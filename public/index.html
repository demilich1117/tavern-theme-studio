高级工具

连接你的酒馆

连接器已针对 SillyTavern 1.19.0 适配。真实预览在酒馆窗口中显示。

  1. 保持本地工作台运行。
  2. 安装连接器后刷新酒馆，在「扩展」面板找到「主题工作台」。
  3. 点击「打开可视化工作台」，从新窗口开始编辑。
下载连接器

将压缩包内的文件夹放入酒馆的用户扩展目录。详细步骤见项目 README。

主题样式

这些设置来自哪里？来自当前主题的 CSS 变量。各项保留原有作用范围；复杂值可直接输入。

样式诊断

列表是匹配到的候选来源，并非完整层叠排名。跨域样式表可能无法读取；计算值以浏览器当前结果为准。

保存 / 恢复版本

给满意的版本留个名字。快照保存在本机，重启后仍可恢复。

恢复会替换当前工程，可用撤销返回。快照文件保持不变。

场景检查

检查当前视口，或轮流检查桌面与手机的六种示例场景。

检查横向溢出、裁切和部件是否出现；不评价主题审美，也不能保证与所有扩展兼容。示例内容独立于真实聊天。
