# 酒馆主题工作台 · Tavern Theme Studio

本地可视化美化编辑器。选择酒馆界面部件、调整属性、在真实酒馆临时预览，或复制小票交给已打开项目的 Agent。完成后导出原生主题 JSON，在酒馆导入保存。

0.9.2 将日常入口收敛为「编辑、素材、修改意见」，常用属性优先，技术详情按需展开。普通导出保留原外链并提供新的导出名称；替换工程前自动保存恢复版本。证据见 [0.9.2 验证](docs/validation-0.9.2.md)。

0.9 新增「素材与装饰清点」：扫描图片、使用位置、伪元素和 CSS 装饰，复制包含冻结快照的主题分析交接。Agent 可导出完整 CSS 与本地图片，再整理素材库及可编辑图层。切换陌生主题可先保存快照、读取为新工程。见 [主题接入与分析](docs/theme-analysis.md)。

当前版本 **0.9.2**，工程 schema v3。独立 Node.js 服务，酒馆中只安装连接器；代码采用 [MIT](LICENSE)，素材许可见 [第三方声明](THIRD-PARTY-NOTICES.md)。适配并实测的宿主为 SillyTavern 1.19.0 / 06bde939f。

已用本机「黑·十四行诗by点心」走通原生切换、工程接入、素材清点、编辑与撤销、导出及原生导入。0.9.2 整理编辑/素材/修改意见入口，补齐普通导出与替换前恢复快照。实测范围与恢复方法见 [验证记录](docs/validation-0.9.2.md)。

## 首次启动

需要 Node.js 22+。从源码启动，在本目录运行：

```powershell
npm ci --omit=dev
npm run package:connector
npm run lab
```

若使用核心 ZIP，运行依赖和连接器包已经包含，解压后直接运行 `npm run lab`。不需要预先生成主题发行包，也不需要 Source Hub 或模型 CLI。

1. 将 `dist/tavern-theme-studio-connector` 放入酒馆 `data/<用户名>/extensions/`；核心 ZIP 用户先解压其中的连接器 ZIP，得到同名文件夹。刷新酒馆。
2. 保持酒馆运行，打开终端打印的 `#tts-lab` 链接（默认酒馆 8000、工作台 19323）。工作台会准备专用虚构测试对话。
3. 确认工作台显示「当前为虚构测试对话」后再查看、标点或测试原生控件。连接诊断在「高级工具 → 连接诊断 → 检查连接与版本」。

默认测试数据保存在 `.local/native-lab/`。已有工程始终保留；可选首次种子为 `npm run lab -- examples/starter.theme.json`。种子只在尚无工程时读取，不能覆盖已有工作台数据。

双击 `start.cmd`、`npm start` 与 `npm run lab` 使用相同的 19323 / `.local/native-lab/`；已有同目录服务会提示继续使用。高级独立模式改用 `npm run start:standalone`（19321 / `.local/`），与默认工程相互独立；旧数据不搬迁、不覆盖。`STUDIO_PORT`、`STUDIO_DATA_DIR` 可调整服务端口和数据目录；`TAVERN_URL` 设置实际酒馆地址。一个数据目录只能运行一个工作台实例。

`npm run doctor` 检查本机 Node、依赖、工作台响应与连接器包。安装/升级/备份与故障恢复见 [发布说明](docs/release.md)、[真实酒馆工作流](docs/native-lab.md)。

## 连接真实酒馆

1. `npm run package:connector` 生成 `dist/tavern-theme-studio-connector.zip` 和同名目录。
2. 将整个 `tavern-theme-studio-connector` 目录放入酒馆 `data/<用户名>/extensions/`。安装后目录下直接是 `manifest.json`、`connector/` 和 `shared/`。
3. 启动或刷新酒馆，在「扩展」面板找到「主题工作台」，点击「打开可视化工作台」，右侧会出现停靠编辑面板。
4. 工作台应显示「真实酒馆」。点击「拾取元素」，面板暂时收起；在酒馆内点击目标后恢复面板。Esc 可取消拾取。也可用「在独立窗口中打开」，将两个窗口并排放置。
5. 首次空工程自动读取当前主题为底层；已有工程会提供读取选择。该操作保留工程的部件规则和高级 CSS，但会清除旧变量编辑并重新识别；可撤销。

真实预览在酒馆窗口中显示。示例 iframe 用于无宿主时试用，不能代表你的扩展、背景与聊天实际效果。连接通过严格校验的 `postMessage` 进行：停靠面板使用 iframe 的 parent，独立窗口使用 opener。内置浏览器建议使用停靠面板；独立窗口需要浏览器支持弹窗与 opener。

预览通过独立临时 `<style>` 生效，不写酒馆主题、设置或聊天。点击「停止预览」、关闭工作台或关闭酒馆页面会清除临时样式。连接失联超过 30 秒也会清理。可通过刷新酒馆立即恢复。工程自动保存发生在工作台本机服务。

## 编辑与交付流程

1. 读取当前主题，或在「主题」中导入主题 JSON。
2. 在部件列表或酒馆中拾取目标。常用属性直接显示；匹配数量与样式来源在「技术详情」；不可见部件需先在酒馆展开。
3. 拖动滑块实时预览，松开后形成一条可撤销记录。颜色、数值旁的还原按钮删除这一项覆盖。部件「重置」只清除当前尺寸范围的规则。
4. 「所有尺寸」设置基础规则；「仅手机」在不超过 767 px 时覆盖。示例可切到 390 px，真实酒馆需调整其窗口宽度实测。
5. 「查看原样」暂时移除整个预览层，取消勾选恢复。
6. 导出主题，在酒馆「用户设置 → UI Theme」中导入并选择，完成持久化。导出不会自动应用到酒馆。
7. 「主题 → 备份工程」导出 `.studio.json`，保留部件规则、变量编辑和高级 CSS。主题 JSON 再导入时，能重新识别变量；任意 CSS 规则不会自动逆向为部件控件。

## 进阶制作工具

- **主题样式**：读取基础 CSS 中的变量、注释、行号、选择器和条件，支持搜索与仅看已修改。数字使用滑块，颜色支持色盘和透明度，比例有常用预设；文本值可按 Enter 或点击「应用」。`var()`、`calc()`、字体列表等保持文本形式。同名变量按原始声明分别编辑，不把手机或局部变量改成全局变量。色盘编辑会转换成 sRGB 十六进制；未编辑的原值原样保留。
- **消息细节与装饰**：展开后可选择正文、名字、时间戳、思考正文与折叠栏、引用、代码、表格、消息操作栏和角色消息的 `::before` / `::after`。拾取到的是当前点击的实例，规则作用于同类所有消息。伪元素通过列表选择，不自动创建装饰内容。
- **样式诊断**：选择属性，比较部件设置与浏览器计算值，并列出匹配到的声明、`!important`、来源样式表和祖先继承候选。无法读取的跨域样式表会明确计数；列表不伪装成完整的层叠排名。
- **保存 / 恢复版本**：保存命名版本，列出它到当前工程的差异，恢复后还能撤销。快照重启后仍在，位于 `.local/native-lab/snapshots/`。工程 JSON 备份不含其他快照；备份整个历史需复制此目录。
- **场景检查**：检查页面横向溢出、部件越界和可能裁切，并导出 JSON 报告。真实酒馆检查当前画面；使用「打开测试对话」准备样本后，通过「原生测试场景」定位内容，再操作原生折叠、编辑、回复切换及侧栏。未出现的部件标为跳过。未连接时保留 6 场景 × 2 尺寸的模拟组合。

[通用起点主题](examples/starter.theme.json) 是随工作台编写的简洁示例，不包含当前用户主题的 CSS；可从「主题」导入试用，再用撤销或快照返回。

撤销：`Ctrl+Z`；重做：`Ctrl+Shift+Z`。编辑文本时保留浏览器原有文本撤销行为。最多保留当前服务会话 100 条撤销记录。重启服务保留最终工程，不保留撤销栈。

## 文件与接口

- `.local/native-lab/project.json`：默认启动方式的当前工程，服务端以临时文件替换方式保存。不要在服务运行时手工覆盖它，使用导入或 API；高级独立启动使用 `.local/project.json`。
- `.local/native-lab/snapshots/`：命名版本；随机编号文件，独立原子保存。
- `shared/variables.js`：保留源位置和范围的变量解析与值替换。
- `shared/core.js`：主题与工程校验、受支持部件、CSS 编译、历史记录。
- `server.js`：本机文件服务、命令 API、SSE 状态推送。
- `connector/`：浏览器桥接、元素拾取与宿主适配。
- `public/`：编辑器与独立示例场景。
- [API 与 Agent 接入](docs/api.md)：CLI、HTTP 与 harness 工作流。
- [设计与技术取舍](docs/design.md)：预览模型、兼容边界与后续方向。
- [验证记录](docs/validation.md)：实际测试环境和结果。

## 当前边界

- 适配依据：SillyTavern **1.19.0 / 06bde939f**。需要主题导出模块、`SillyTavern.getContext()`、`powerUserSettings` 和标准界面选择器。其他版本尚未认证。
- 支持 20 类标准部件。第三方扩展的新组件、任意 DOM 重排、悬浮/聚焦专用规则与交互逻辑不属于这一版。
- 导入主题的完整字段会保留到导出。临时预览支持映射的主题颜色变量、基础变量与 CSS；`chat_display` 等原生行为开关不会临时切换，因此包含这些变化的主题须在酒馆导入后再检查。
- 原有主题、内联样式、扩展样式和更强的 `!important` 规则可能覆盖生成 CSS。诊断读取当前计算值与可访问的候选来源；不是完整 CSS 编译器或自动修复器。容器查询、作用域、嵌套规则、动画等仍需结合开发工具核实。
- 变量面板只编辑基础主题 `custom_css` 内、使用普通未转义变量名的声明，不抓取外部 `@import` 或扩展文件中的变量。原主题已有语法问题可能影响识别和预览；原文始终保留。高级 CSS 里的变量仍在高级编辑器中修改。
- 高级 CSS 会按原文应用；其中的外部字体和背景地址会由浏览器加载。外部图片、字体没有打包进主题 JSON。
- 同一服务目前只有一个当前工程；多个页面与 CLI 共享它。写入同时检查运行会话、稳定工程 ID、指纹与 revision；重启后的旧请求也会被拒绝。
- Agent 可通过 CLI / HTTP 编辑和导出；尚未提供模型聊天面板、MCP 服务或自动截图工具。

项目代码采用 MIT 许可证；随包素材保留各自来源和许可说明。本地工程尚未推送或发布到托管平台。
