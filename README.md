# 酒馆主题工作台 · Tavern Theme Studio

**和 Agent 从一个想法做出美化，在真实酒馆里边看边改。** 从认识界面、看图讨论方向开始，逐步完成原生主题；也可以直接调整现有主题的颜色、圆角、间距和装饰。满意后导出主题 JSON，在酒馆中导入使用。

当前版本 **0.9.2** · Node.js **22+** · 已实测 SillyTavern **1.19.0 / 06bde939f** · [MIT 代码许可](LICENSE)

[下载核心安装包](https://github.com/demilich1117/tavern-theme-studio/releases/latest) · [浏览源码](https://github.com/demilich1117/tavern-theme-studio) · [自动检查](https://github.com/demilich1117/tavern-theme-studio/actions/workflows/ci.yml)

首次使用请下载 Release 附件中的 `tavern-theme-studio-0.9.2-core.zip`，完整解压后开始；包含运行依赖、连接器、指南和漫画。GitHub 自动提供的 Source code 压缩包用于源码开发。

电脑上运行工作台，酒馆里安装连接器。日常入口是「编辑」「素材」「修改意见」；还没有设计方案时，打开「从零共创」。

## 从零与 Agent 共创

不用先有成品主题，也不用先懂 CSS 或安装工作台。可以直接和 Agent 聊；工作台在制作样板时提供真实酒馆预览、部件定位和微调。已经启动工作台时，**「从零共创」** 能帮你把想法和当前工程一起带给 Agent。

1. **聊想法。** 例如「暗黑童话，手机为主，布局可以大改」。直接对 Agent 说即可；也可在「从零共创」里点 **「复制给 Agent，开始共创」**，粘贴到已打开本项目的 Agent 对话。有参考图时另附图片。
2. **看图，说喜欢哪里。** Agent 先认识酒馆原生部件，再给出构图、排版和装饰有实质区别的方向。你直接说「喜欢 A 的书页感，装饰少一点」即可，布局也可以大胆重做。
3. **试样板，边看边改。** 大方向敲定后，Agent 尽量照选定参考图制作，落实布局、头像和消息形态，用真实截图对照后接入工作台供你试用。你用「拾取元素」微调字号、间距等，用「标点评论」指出要改的地方，或直接在对话里提意见。Agent 接着完善，满意后导出并导入酒馆。

**设计记录、接入预览和检查交给 Agent；用户只需说想法、看图和试效果。** 已在同一项目对话里，标注后告诉 Agent「标好了」即可；首次或换 Agent 时再复制交接。工作台不会自行启动 AI 或监听对话，参考图片需另附。

起步想法会留在当前浏览器，需要时可展开「想法怎么保存？」下载；Agent 另外维护设计记录，两者不会自动同步。换对话时，把 Agent 整理的记录和参考图带过去即可。已有明确参考可以缩短探索，小幅修补可直接编辑。更多说明与 Agent 制作规范见 **[从零共创指南](docs/co-design.md)**。

## 普通用户入门

第一次的目标很简单：**连上酒馆 → 改一处样式 → 导出 → 在酒馆里保存。**

### 1. 启动工作台

先准备 Node.js 22+，并保持你的酒馆运行。安装包和源码的启动方式如下，选择你手上的一种。

**拿到核心安装包：** 解压 `tavern-theme-studio-0.9.2-core.zip`，进入包内的 `tavern-theme-studio` 文件夹。Windows 可以双击 `start.cmd`；也可以在此目录打开终端运行：

```powershell
npm start
```

核心包已包含运行依赖和连接器 ZIP。

**使用完整源码：** 在本项目目录打开终端，首次运行：

```powershell
npm ci --omit=dev
npm run package:connector
npm run lab
```

之后可直接双击 `start.cmd` 或运行 `npm start`。运行期间保持这个终端开启。

### 2. 给酒馆安装连接器

将整个 `tavern-theme-studio-connector` 文件夹放入酒馆的 `data/<用户名>/extensions/`。核心包用户先解压 `dist/tavern-theme-studio-connector.zip`；源码用户使用刚生成的 `dist/tavern-theme-studio-connector/`。

安装后应是下面的层级，**不要多套一层同名目录**：

```text
SillyTavern/
└─ data/<用户名>/extensions/
   └─ tavern-theme-studio-connector/
      ├─ manifest.json
      ├─ connector/
      └─ shared/
```

刷新或新开一个酒馆标签，在「扩展」面板确认出现「主题工作台」。

### 3. 进入专用测试对话

打开启动终端打印的 **`#tts-lab` 链接**，等待工作台显示 **「当前为虚构测试对话」**。这是用来检查主题的专用样本，包含普通消息、长文、思考栏、代码、表格和图片。

默认酒馆地址是 `http://127.0.0.1:8000`，工作台是 `http://127.0.0.1:19323`。酒馆地址不同的设置方法见 [真实酒馆工作流](docs/native-lab.md)。

也可以从酒馆「扩展 → 主题工作台」选择「在新标签打开测试工作台」。连接问题先看 [常见问题](#faq)。

### 4. 留一个版本，再动手

先点「保存 / 恢复版本」，保存名为「开始修改前」的版本。

首次空工程会读取酒馆当前主题。想改另一份 JSON，可从「主题 → 导入工程 / 酒馆主题」选择文件；想接入酒馆里刚选好的主题，可从「主题 → 接入酒馆当前主题」核对名称后「保存快照并切换」。替换前会自动保留恢复版本。

接下来试着把角色消息改得更舒服：

1. 点击「拾取元素」，再点击酒馆里的一条角色消息；也可以直接从「界面部件」选择「角色消息」。
2. 调整背景颜色、圆角或内边距，在真实酒馆里观察效果。
3. 勾选「查看原样」比较前后，取消勾选继续预览。
4. 不满意就 `Ctrl+Z` 撤销；颜色、数值旁的还原按钮可只还原这一项。

拾取的是一条消息，部件规则会作用于**同类消息**。暂时看不到的部件，先在酒馆里展开它再拾取；`Esc` 可取消拾取。

### 5. 再看一眼手机效果

先在「所有尺寸」中调整基础样式；需要单独照顾窄屏时再切到「仅手机」，默认作用于宽度不超过 **767 px** 的画面。

连接真实酒馆时，要缩窄**酒馆窗口**检查效果。示例预览的「手机」按钮只改变示例尺寸。手机上面板挡住消息时，先收起工作台再观察阅读区。

### 6. 导出，并在酒馆里保存

1. 点击右上角「导出主题」，填写一个新名称，例如「芝士夜话-v1」。
2. 点击「下载酒馆主题 JSON」。
3. 到酒馆「用户设置 → UI Theme」导入该文件，再选择它。

**临时预览 ≠ 保存主题。** 导出也不会自动应用到酒馆；完成原生导入和选择后，才会留下主题效果。酒馆拒绝同名主题导入，继续迭代时请换一个导出名称。

普通导出会把本地图片放进 JSON，保留原有图片和字体外链；含外链的主题仍需要网络。

### 下次接着改，应该存什么？

| 保存方式 | 用途 |
| --- | --- |
| **主题 JSON** | 导入酒馆、分享最终效果 |
| **工程备份 `.studio.json`** | 保留部件规则、变量修改、图层和高级 CSS，回到工作台继续编辑 |
| **保存 / 恢复版本** | 给当前工程留一个可恢复的阶段；重启后仍在 |

继续制作前，建议从「主题 → 备份工程」留一份工程备份。工程在本机自动保存，默认目录为 `.local/native-lab/`；升级或换电脑时的完整备份方法见 [备份与恢复](docs/advanced-guide.md#backup)。

## 进阶使用

已经走通一次入门流程后，按你的目标选择工具：

| 目标 | 操作入口与下一步 |
| --- | --- |
| 看懂陌生主题用了哪些图和装饰 | 「素材 → 主题图片」查看使用位置，点「复制分析给 AI」；[主题分析](docs/theme-analysis.md) |
| 换图、移动装饰、调整图层 | 「素材 → 素材库 / 可调装饰」；[素材与图层](docs/advanced-guide.md#materials) |
| 更细致地调整正文、思考栏、引用与表格 | 「展开消息细节与装饰」「主题样式」「高级 CSS」；[细节编辑](docs/advanced-guide.md#styling) |
| 让 Agent 帮你改指定位置 | 「标点评论」写需求 → 告诉当前 Agent 已标好（首次可复制小票）→ 检查并验收；[协作流程](docs/advanced-guide.md#agent) |
| 修改 CSS 源码后自动看到效果 | 「高级工具 → 源码同步」绑定构建配方；[源码同步](docs/source-build.md) |
| 做多尺寸检查、离线交付或批量操作 | 「场景检查」、导出高级选项、CLI；[验证与交付](docs/advanced-guide.md#delivery) |

**自己能调的直接调，需要 Agent 改的地方再标注。** 同一项目对话里告诉 Agent 已标好，它便可读取小票；首次交接使用「复制给 Agent」。工作台不会自动启动 AI，小票改完后由你检查效果并点击「验收通过」。

完整说明包括变量作用范围、CSS 诊断、断点、CLI 示例、快照和素材备份，见 [进阶指南](docs/advanced-guide.md)。

## 常见问题

| 遇到的情况 | 先这样处理 |
| --- | --- |
| 双击启动后提示缺少依赖 | 源码用户在项目目录运行一次 `npm ci --omit=dev`；核心包用户确认已完整解压，且有 `node_modules/` |
| 酒馆里没有「主题工作台」 | 核对连接器目录层级和 `manifest.json` 位置，再刷新或新开酒馆标签 |
| 只有「示例预览」，没连上酒馆 | 保持服务运行，从酒馆连接器进入；「高级工具 → 连接诊断 → 检查连接与版本」查看原因 |
| 改了没有效果 | 先核对「所有尺寸 / 仅手机」；再展开「技术详情」确认匹配情况，查看计算值与样式来源 |
| 关闭面板后效果消失 | 当前是临时预览；按第 6 步导出，并在酒馆原生导入后选择 |
| 导入提示同名主题 | 在导出窗口换一个新名称，再下载和导入 |
| 换主题后想找回旧工程 | 「保存 / 恢复版本」中恢复替换前版本；当前会话也可撤销 |
| 重启后不能撤销刚才的步骤 | 重启保留工程和命名版本；撤销栈只保留当前服务会话，最多 100 条 |

连接或启动仍有问题时，在项目目录运行 `npm run doctor`。它会检查 Node、依赖、工作台响应和连接器包。安装、升级及锁冲突的处理见 [发布与恢复说明](docs/release.md)。

## 支持范围与文档

支持 20 类标准界面部件，以及变量、图层、容器和断点编辑。已实测的宿主是 **SillyTavern 1.19.0 / 06bde939f**；其他版本、第三方扩展特殊组件、实体手机、群聊和真实流式需要另行验证。

导入主题的完整原生字段会保留到导出；`chat_display` 等行为开关不会随临时预览切换，需原生导入后再检查。一个工作台服务只有一个当前工程，多个页面和 CLI 会共享它。
