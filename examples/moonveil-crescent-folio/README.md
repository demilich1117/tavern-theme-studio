# 月誓 · 龙廷 2.2.4 — 月弧浮页

本版让电脑端伏睡银龙探进渐隐页边，伏在阅读层下面。龙的大小跟随窗口尺寸，拉宽阅读区只改变遮叠关系，不再把它压缩到右侧空隙里。2560 × 1215 下，80%、95% 和 100% 原生阅读宽度都保持约 1040 × 496 px 的等比绘制体量；文字下方补充柔和的阅读底色。手机小龙、滚动书签、对称月牙菜单与原有编辑修复继续沿用。

## 使用

1. 在酒馆「用户设置 → UI 主题」导入发行包中的 `moonveil.theme.json`，选择「月誓 · 龙廷 2.2.4 — 月弧浮页」。
2. 页面宽度、字体比例、头像、时间戳、消息编号继续沿用原生设置，主题不重置这些偏好。
3. `companion/` 是推理编辑焦点配套扩展，安装说明见其 README。只导入 JSON 已包含全部装饰和编辑菜单布局修复；让推理光标从开头开始需要该扩展。它不修改消息或酒馆核心。
4. `moonveil.studio.json` 是可编辑工程；`theme.css` 是完整 CSS；`source/theme.template.css` 是布局源文件。双击 `preview.html` 可离线查看虚构对话和编辑场景。

图片全部内嵌，无图床、CDN 或本机服务依赖。2.2.3 及更早的发行目录保留。

## 装饰与阅读

- 成年银龙直接伏睡在右下岩面，头枕前爪、双翼收拢。龙头和前爪可伸入页边，文字与阅读底色位于它上面，银鳞从边缘渐渐显露。窄阅读栏露出更多龙身，宽阅读栏让它藏在书页后；同一窗口内，阅读宽度不会改变龙的绘制比例。最大等比绘制宽度 1040 px，矮窗口另受视口高度限制，尾身可在右侧自然延伸。
- 下半页增加局部渐隐阅读底色，衔接背景和银龙；上半页继续保留城堡与月色的通透感。遮罩仅作用于装饰底层，正文、编辑框和原生抽屉不受遮罩裁切。
- 1000 px 及以下使用独立绘制的 Q 版睡龙，放在输入框上方专属角落。快捷回复为它留出侧边空间；没有快捷回复时预留小块高度，避免覆盖正文。
- 小龙书签直接绘制在 Chromium 原生滚动滑块上，可正常拖动；其他浏览器保留细滚动条回退。
- 月牙菜单沿用 2.2.1 的对称布局。背景不增加巨龙；字号、行距、便笺和阅读宽度机制延续已确认方案。
- 装饰不接受指针事件；原生抽屉、编辑、发送/停止等交互仍由酒馆处理。

## 编辑修复

编辑工具栏明确占据消息头的工具区，折叠推理标签、展开推理和普通消息都有对应位置。手机中工具栏自然换行到消息头下方、内容框上方。

酒馆 1.19.0 主动把推理编辑的光标设为文末。配套扩展仅在本主题下从推理小铅笔进入编辑时，把光标和编辑框滚动位置移到开头，并让推理工具栏可见；取消、保存及普通正文编辑的原生光标行为保留。

## 验证与重建

验证版本为真实 SillyTavern 1.19.0 / 06bde939f、Chrome。具体视口和检查记录见 `validation/design-qa.md`。公开截图全部采用虚构演示；真实酒馆只发布不含正文的几何数据。本轮检查 45–100% 桌面阅读宽度、1440 px 小窗口、600 px 矮窗口、1000 px 断点和 393 px 手机。原窗口主题、80% 阅读宽度、未完成编辑和聊天滚动位置已恢复。此前已知的 25% 极窄消息头拥挤不在本轮修改范围；手机视口测试不等于实体软键盘测试。

源项目执行 `npm run build:folio`、`npm run package:folio`。发行包可编辑 `source/theme.template.css` 后运行 `node source/build.mjs`，同步重建主题、工程、CSS 和离线预览。素材与生成提示词来源见 `ARTWORK.md`。
