# 月誓 · 龙廷 2.0 — 夜幕浮雕（2.0.1 姿态修订）

从空白工程设计的 SillyTavern 1.19.0 巨龙主题。依据已选定的第二套夜间概念重构；没有以用户原主题为底层。

银蓝巨龙的一只前爪搭住上沿，另一只通过连续肩臂抓住右侧银框；龙爪头像环包围实际角色头像。界面使用靛蓝底板、柔和灰白正文、少量月紫强调。四张 Image Gen 位图提供立体装饰，不再使用旧版 SVG 纹章、霜色纸页、标题和装饰口号。

## 使用

- [交互演示](http://127.0.0.1:19321/moonveil.html)，或离线打开 `preview.html`。
- 酒馆「用户设置 → UI 主题」导入 `moonveil.theme.json`，选择 **月誓 · 龙廷 2.0 — 夜幕浮雕**。本机已经保存并选中；1.1 保留。
- [工作台](http://127.0.0.1:19321/) 已载入 `moonveil.studio.json`，可继续调整色彩、字号、头像、间距和装饰透明度。
- 原生「页面宽度」有效，桌面默认 92%。主题跟随 `--sheldWidth`，到达工具栏安全边距后停止扩张。600px 以下以完整可用宽度优先。

主题 JSON 自包含四张 WebP，约 149 KB 图像 / 217 KB CSS；不依赖图片服务器、外部字体或工作台进程。演示的图标字体和示例头像只属于演示，不写入用户角色卡。

## 布局

- 桌面正文 20px、1.9 行高；手机 17px、1.85 行高。消息使用可用宽度，通过原生页面宽度控制行长。
- 龙与边框使用独立透明层和接触阴影。聊天滚动区上方保留固定避让区域，滚动后正文仍不会被上沿龙首遮住。
- 原生角色管理从左侧打开，宽580px；用户设置等复杂面板宽1020px，按视口收缩。用户设置自适应一至三列。
- 手机工具栏横排、头像移到正文上方，整只龙等比例缩小并为侧爪避让；不会缩小整张桌面截图。
- 装饰层 `pointer-events:none`。原生抽屉和内嵌折叠栏仍由酒馆负责展开/收起。

## 文件与构建

| 文件 | 用途 |
| --- | --- |
| `moonveil.theme.json` | 导入酒馆 |
| `moonveil.studio.json` | 工作台工程 |
| `theme.css` | 带注释的主题源文件 |
| `preview.template.html` / `preview.html` | 演示源码 / 自包含成品 |
| `assets/night/*.webp` | 本版生产素材 |
| `assets/night/*.original.png` | 原始生成图，仅源工程保留 |
| `assets/night/*.prompt.txt` | 内置 Image Gen 提示词 |
| `assets/night/GENERATION.md` | 分层与编码说明 |
| `validation/night-*` | 本版验证证据 |
| `WORKFLOW.md` | 制作经验 |

在工作台项目根目录运行 `node scripts/build-moonveil-theme.js`。需要重新编码时，先运行 `node scripts/prepare-night-art.cjs <本机 sharp 模块路径>`。Sharp仅用于缩放及格式编码，保留透明通道。

主题包包含成品、源码、生产素材和提示词；历史概念、原始PNG和用户酒馆截图不进入主题包。示例字体为 Font Awesome Free 6.5.2，Fonticons Inc.，SIL OFL 1.1；许可证位于 `assets/night/Font-Awesome-LICENSE.txt`。

验证：15项现有测试通过；真实桌面酒馆的页面宽度和七个菜单已实测。390/900/1440/2048px响应式验证来自固定尺寸示例，不能视为实体手机或所有第三方扩展的兼容认证。

## 2.0.1 姿态修订

移除独立小侧爪，把上方右前爪移到右框，龙身与两只前爪使用同一张透明素材。桌面右侧为前臂保留安全边距，正文避开内钩的爪尖；窄屏使用完整的顶部避让。本机仅更新已有2.0主题CSS，保留用户70%页面宽度。旧稿保存在 `iterations/before-corner-2.0.1/`。
