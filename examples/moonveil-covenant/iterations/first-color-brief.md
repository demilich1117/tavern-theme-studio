# 烬誓 · 龙廷 / CINDER COVENANT

从空白工程制作的西幻巨龙主题；不继承用户现有主题的任何 CSS、变量、作者内容或布局。目标宿主为 SillyTavern 1.19.0（06bde939f）。

视觉语言：黑曜石、熔火朱红、旧金箔、骨白文字；原创巨龙立绘；锐利切角、铭文边框、契约页签、印玺头像、档案式时间戳。避免把所有文字放在高对比图片上，阅读区用独立实色/半实色层。

布局：桌面左侧龙像、主题铭文与竖向工具栏，右侧阅读页与固定输入区；平板收窄画面；手机改为顶部短幅主视觉和横向工具栏。真实抽屉维持原来的展开/关闭行为，只改位置、表面与控件。

部件：角色消息为带印玺的契约页，我方消息为收窄的右对齐便笺；思考区为可折叠秘闻；引用为誓言边栏；代码/表格为档案面板；输入区为命令台。编辑、滑动消息、流式生成和第三方消息 iframe 的功能继续由酒馆管理。

交付：含嵌入图像的独立主题 JSON、可继续编辑的工作台工程、可读 CSS 源文件、原始/压缩素材、独立预览页、制作与验收记录。

工程变量分为色彩、阅读布局、消息几何、图片与装饰、手机范围。图像直接嵌入最终 CSS，主题不依赖工作台端口或第三方图床。图像编码使用 WebP，仅压缩格式，不重绘素材。
