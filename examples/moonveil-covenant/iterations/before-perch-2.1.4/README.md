# 月誓 · 龙廷 2.1.3 — 月相典籍

在2.0.6夜幕浮雕上继续设计消息内部：角色消息为银饰典籍页，用户消息为紫绸信笺，思考区为月相封缄与内页。三类消息使用不同的边框、材质和装饰，正文中心保持清晰。

## 使用

- 在酒馆「用户设置 → UI主题」导入本包 moonveil.theme.json，选择「月誓 · 龙廷 2.1 — 月相典籍」。
- 离线打开 preview.html，或查看 http://127.0.0.1:19321/moonveil.html 的交互演示。
- 工作台可导入 moonveil.studio.json，继续调整色彩、字号、间距、角饰尺寸和装饰强度。
- 本轮交付文件；真实酒馆只进行了临时预览，验证后已恢复原主题。原2.0.6、2.1.0、2.1.1和2.1.2目录与压缩包继续保留。

目标宿主为 SillyTavern 1.19.0 / release / 06bde939f。导入整份主题会应用其原生外观默认值；如果需要保留自己当前的页面宽度、字体比例等配置，可只将导出的 custom_css 更新到当前主题，再通过酒馆原生更新按钮保存。

## 2.1.3 外框对齐与顶部收紧

银框素材上沿带透明边距，原来的统一-12px偏移让可见内线比聊天裁切边界低约18px。现在桌面外框上沿改为-30px，与聊天区顶部对齐，正文滚动时不再露到框顶上方；左右及下沿沿用原位，角饰尺寸和素材保持不变。

桌面龙宽改为min(60vw,600px,62dvh,var(--sheldWidth,92vw))，顶部余量由12px减到8px。整龙等比例缩小约6%～9%，龙头仍默认不避让。1685×785聊天高度增加16.16px，1366×768增加15.89px；393×852手机布局保持原样。

实际SillyTavern 1.19.0中通过临时CSS预览验证：当前92%页面宽度保留，龙宽640px变为600px，聊天区高度增加14.31px，框顶与阅读区对齐。验证后已恢复原主题和连接器入口。记录与干净截图在validation/frame-2.1.3/；真实聊天截图仅留在源工程output/，不进入分发包。

## 2.1.2 龙头遮挡修复（继续沿用）

原生酒馆的聊天区是带z-index:30的flex子项，而龙图位于10；滚动正文卡片时会盖住龙头。现在明确设置聊天区z-index:0，将消息、iframe和高层级滑动按钮限制在聊天区内部，银框和银龙正常叠在上方。装饰仍不接收指针事件，菜单和输入区保留原有层级。

演示页补入了原生聊天层级规则，先复现遮挡再验证修复。实际SillyTavern 1.19.0中也通过工作台临时预览了本轮生产CSS，保留当前77%页面宽度；龙头完整显示，结束后恢复原CSS、外观和连接器入口。没有更新用户保存的主题。

1366×768、1685×785、1280×600及393×852回归中，聊天高度与2.1.1完全相同，桌面仍默认不避让。记录与干净演示截图在validation/layering-2.1.2/。真实聊天截图仅留在源工程output/，不进入分发包。

## 2.1.1 阅读空间（继续沿用）

2.1.1引入桌面整龙的宽、高限制，并取消为龙头预留的整行顶部空间，让龙头直接叠在阅读区右上角。2.1.3继续沿用这一布局，并将约束收紧为60vw、600px上限和62dvh。龙形、爪子接触位置与材质保持不变。

1366×768演示中聊天可见高度由304.91px增加到491.89px，多出186.98px；1685×785多出184px，2560×1215多出156.61px。手机原有布局保持不变。

演示“阅读设置”提供桌面龙头避让开关，可直接比较两种方案。原生主题默认不避让；如需保留顶部空间，可将CSS里的--cc-head-clearance设为clamp(32px,calc(var(--cc-dragon-width) * .125),130px)。龙头可能与滚动经过右上区域的少量文字重叠。

阅读空间记录及截图在validation/reading-2.1.1/；validation/messages-2.1/是消息设计验证。该轮演示未包含原生聊天层级30，龙头遮挡已由2.1.2修复并重新验证。

## 消息设计

- 角色消息：银鳞四角、双线内框、暗蓝底纹和独立翼月页尾；长消息不会拉伸中央翼纹。
- 用户消息：紫绸底纹、缝线内框、银色折角和紫月印玺。仅首段为印玺预留空间，后续段落正常使用宽度。
- 思考折叠：月相封缄、月牙徽记、细线内页；保留酒馆自己的箭头、折叠和编辑状态。
- 正文细节：名字与时间旁的星形分隔线，引用改为带菱形标记的边注，代码与表格保留独立滚动及换行。
- 手机：缩小角饰和印玺，头像仍在名字左侧，正文使用整行宽度；隐藏头像后名字的留白随之取消。

既有用户定稿银龙、夜间背景、头像环、外框与菜单素材沿用2.0.6。桌面正文20px、1.9行高；手机17px、1.85行高，跟随原生字体比例。原生页面宽度仍通过 --sheldWidth 控制。发送、停止、菜单、消息操作与第三方悬浮控件沿用已有行为。

## 构建

在工作台根目录运行 node scripts/build-moonveil-theme.js。完整源码在 examples/moonveil-covenant/，包括原图、概念、备份和验证证据。生产装饰可通过 node scripts/prepare-message-art.cjs <sharp模块路径> 重新编码。分发目录通过 node scripts/package-moonveil-theme.js 生成，固定路径为 dist/moonveil-covenant-2.1.3/。
