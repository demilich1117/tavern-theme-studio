# 月誓 · 龙廷 2.1.0 — 月相典籍

在2.0.6夜幕浮雕上继续设计消息内部：角色消息为银饰典籍页，用户消息为紫绸信笺，思考区为月相封缄与内页。三类消息使用不同的边框、材质和装饰，正文中心保持清晰。

## 使用

- 在酒馆「用户设置 → UI主题」导入本包 moonveil.theme.json，选择「月誓 · 龙廷 2.1 — 月相典籍」。
- 离线打开 preview.html，或查看 http://127.0.0.1:19321/moonveil.html 的交互演示。
- 工作台可导入 moonveil.studio.json，继续调整色彩、字号、间距、角饰尺寸和装饰强度。
- 本轮只制作文件，没有更新用户已安装的酒馆主题。原2.0.6目录和压缩包继续保留。

目标宿主为 SillyTavern 1.19.0 / release / 06bde939f。导入整份主题会应用其原生外观默认值；如果需要保留自己当前的页面宽度、字体比例等配置，可只将导出的 custom_css 更新到当前主题，再通过酒馆原生更新按钮保存。

## 本轮设计

- 角色消息：银鳞四角、双线内框、暗蓝底纹和独立翼月页尾；长消息不会拉伸中央翼纹。
- 用户消息：紫绸底纹、缝线内框、银色折角和紫月印玺。仅首段为印玺预留空间，后续段落正常使用宽度。
- 思考折叠：月相封缄、月牙徽记、细线内页；保留酒馆自己的箭头、折叠和编辑状态。
- 正文细节：名字与时间旁的星形分隔线，引用改为带菱形标记的边注，代码与表格保留独立滚动及换行。
- 手机：缩小角饰和印玺，头像仍在名字左侧，正文使用整行宽度；隐藏头像后名字的留白随之取消。

既有用户定稿银龙、夜间背景、头像环、外框与菜单素材沿用2.0.6。桌面正文20px、1.9行高；手机17px、1.85行高，跟随原生字体比例。原生页面宽度仍通过 --sheldWidth 控制。发送、停止、菜单、消息操作与第三方悬浮控件沿用已有行为。

## 文件

| 文件 | 用途 |
| --- | --- |
| moonveil.theme.json | 自包含酒馆主题，导入只需要此文件 |
| moonveil.studio.json | 可编辑工程 |
| theme.css | 可读CSS，构建时替换素材占位符 |
| preview.html / preview.template.html | 自包含演示 / 演示源码 |
| assets/night/MESSAGE-ARTWORK.md | 新装饰来源、完整提示词路径、分层和编码说明 |
| assets/night/*.webp | 7张主题生产素材和2张仅供演示的头像 |
| validation/messages-2.1/ | 本轮干净演示截图、尺寸记录与验证说明 |
| release.json | 分发文件清单、大小和SHA256 |

内置 Image Gen 先生成概念，再分别生成银鳞典籍框、紫月印玺、月相封缄。三个新素材均带真实透明通道；提示词随包保留。当前主题内嵌7张WebP，总计324,604 bytes图像，460,546字符CSS。主题不依赖图片服务器、外部字体或工作台进程。原始PNG及概念只留在源工程。

## 构建

在工作台根目录运行 node scripts/build-moonveil-theme.js。完整源码在 examples/moonveil-covenant/，包括原图、概念、备份和验证证据。生产装饰可通过 node scripts/prepare-message-art.cjs <sharp模块路径> 重新编码。分发目录通过 node scripts/package-moonveil-theme.js 生成，固定路径为 dist/moonveil-covenant-2.1.0/。

## 验证范围

主题与工作台工程导入/导出往返、自包含资源检查、原生RGBA颜色格式和JavaScript语法检查通过。独立演示验证普通消息、长文、短句、引用、代码、表格、思考展开/收起/编辑、隐藏头像、空聊天和多行输入，覆盖320px窄屏、393px手机、横屏、1000/1001px断点及桌面。

本轮以匹配版本的本地酒馆源码核对思考块和消息DOM，但没有在用户实际酒馆导入或验证模型流式生成，没有测试实体手机或第三方消息iframe。详见 validation/messages-2.1/qa.md。
