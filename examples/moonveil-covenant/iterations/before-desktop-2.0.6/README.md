# 月誓 · 龙廷 2.0 — 夜幕浮雕（2.0.5 图标对齐与紧凑手机布局）

从空白工程设计的 SillyTavern 1.19.0 巨龙主题。依据已选定的第二套夜间概念重构；没有以用户原主题为底层。

整只银龙采用用户提供的最终透明立绘：左翼展开，右翼向后半收拢，保留自然的不对称；一只前爪搭上沿，另一只通过连续肩臂扣住右框。直接使用定稿，仅缩放和转换格式，保留原画造型与细节。龙爪头像环包围实际角色头像，菜单保留银鳞紫晶边框。界面使用靛蓝底板、柔和灰白正文、少量月紫强调。

## 使用

- [交互演示](http://127.0.0.1:19321/moonveil.html)，或离线打开 `preview.html`。
- 酒馆「用户设置 → UI 主题」导入本包 `moonveil.theme.json`，选择 **月誓 · 龙廷 2.0 — 夜幕浮雕**。本次已将修复保存到当前酒馆主题，保留用户74%的页面宽度。
- [工作台](http://127.0.0.1:19321/) 可导入 `moonveil.studio.json`，继续调整色彩、字号、头像、间距和装饰透明度。
- 原生「页面宽度」有效，桌面默认 92%。主题跟随 `--sheldWidth`，到达工具栏和完整右翼所需的安全边距后停止扩张。手机阅读框居中撑满可用宽度，侧爪允许在视口边缘裁切。

主题 JSON 自包含四张 WebP，共 244,052 bytes 图像 / 345,718 字符 CSS；本版工作台主题 CSS 上限为 1,000,000 字符，高级附加 CSS 仍限制为 250,000 字符。不依赖图片服务器、外部字体或工作台进程。演示的图标字体和示例头像只属于演示，不写入用户角色卡。

## 布局

- 桌面正文 20px、1.9 行高；手机 17px、1.85 行高。消息使用可用宽度，通过原生页面宽度控制行长。
- 龙与边框使用独立透明层和接触阴影。聊天滚动区上方保留固定避让区域，滚动后正文仍不会被上沿龙首遮住。
- 原生角色管理从左侧打开，宽580px；用户设置等复杂面板宽1020px，按视口收缩。用户设置自适应一至三列。
- 手机工具栏横排、头像移到正文上方，立绘等比例缩小，阅读框居中；侧爪在屏幕边缘自然裁切。横屏进一步缩小整龙，为正文和输入框保留空间。
- 装饰层 `pointer-events:none`。原生抽屉和内嵌折叠栏仍由酒馆负责展开/收起。

## 2.0.5 图标对齐与紧凑手机布局

菜单图标填满所属按钮，用网格居中，消除 Font Awesome 固定宽度与内边距叠加造成的图案/点击框偏移。发送按钮保持正圆并居中：桌面42×42px，手机34×34px；继续保留宿主的发送/停止显示状态。

手机完整保留用户定稿，取消局部剪裁，整龙按 `min(56vw,220px,48dvh)` 缩小；翼冠从菜单下方开始，上爪仍贴聊天框上沿。393px视口下龙宽220px，阅读框顶部约121px。侧爪允许在屏幕右边缘自然裁切。根据用户最终要求，悬浮控件仍由各自插件管理，主题不调整它们的位置。

背景由900×600升级为原始1536×1024，并提高WebP编码质量，改善桌面放大后的细节。龙、头像框、银框素材保持不变。背景清晰度仍受原图分辨率限制，没有插值冒充更高分辨率。

## 2.0.4 手机布局修复（历史）

酒馆原生手机样式把body设为fixed，而html自身带transform，导致原先依赖top/bottom的阅读框以零高度根节点定位。现在html明确跟随动态视口高度，聊天区重新填满输入框上方。

窄屏断点与宿主对齐到1000px，并针对宿主的width/left强制规则保持阅读框居中、设置抽屉边距。手机阅读框左右各8px，平板左右各12px，取消右侧装饰专用空白。手机输入栏图标改为18px，左右按钮组横排、不换行，发送按钮34px；保留原生发送/停止按钮的显示状态。演示页加入对应宿主布局约束，避免纯演示漏报。龙素材保持不变。

## 2.0.3 透明定稿（历史）

最终采用用户提供的 `ChatGPT Image Sep 30, 2026, 08_40_07 AM.png`，原图1902×827，带真实透明通道。源工程保留逐字节一致的 `dragon-user-final-v3.original.png`，生产使用1040×452的WebP。未采用误传的08_50_00不透明图片，也未继续重绘定稿。

已移除 2.0.2 单独补上的右翼层；两翼与身体使用同一图片和同一宽度。以横框和右框的接触线定位，呈现趴在阅读框上的姿态。桌面与手机均预留右翼空间；顶部为完整翼冠留出空间，横屏按视口高度缩小。

保留 2.0.2 的菜单银框。本轮验收见 `validation/comic-qa.md`；2.0.1、2.0.2 成品继续保留。未采用的均衡双翼草稿不参与当前构建。

## 2.0.2 双翼与菜单银框（历史）

新增与原龙同风格的透明右翼，放在肩臂及阅读框后方，根据右侧空隙等比例展开，保留 16px 视口边距。桌面 70% 页面宽度可清楚看到右翼；页面越宽，右翼越收拢。900px 以下不显示外侧右翼，保留正文空间。

竖向工具栏复用银鳞紫晶四角，横排工具栏缩小边框。装饰不接收指针事件，不改变原生抽屉的定位基准。原龙首、两只前爪与聊天阅读区沿用 2.0.1。

生产素材和生成提示词见 `assets/night/dragon-right-wing.*`；本轮验收见 `validation/wings-qa.md`。旧版保存在原 `dist/moonveil-covenant-2.0.1/`，源稿另备份于 `iterations/before-wings-2.0.2/`。

## 2.0.1 姿态修订

移除独立小侧爪，把上方右前爪移到右框，龙身与两只前爪使用同一张透明素材。桌面右侧为前臂保留安全边距，正文避开内钩的爪尖；窄屏使用完整的顶部避让。本机仅更新已有2.0主题CSS，保留用户70%页面宽度。旧稿保存在 `iterations/before-corner-2.0.1/`。
