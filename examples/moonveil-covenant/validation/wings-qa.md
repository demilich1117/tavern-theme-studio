# 2.0.2 双翼与菜单银框验收

日期：2026-09-30。基于用户指定的 2.0.1 成品，新增右翼及菜单装饰。

设计约束：夜间阅读为主，龙与银框位于边缘；沿用月白银鳞、靛蓝翼膜、夜蓝底幕、灰白正文及月紫水晶。龙肩向右伸出的翼膜平衡原有左翼；菜单复用同一鳞骨边框。字体、正文层级、消息间距和底板沿用既有主题。菜单装饰向外延伸，避免挤压图标。

- 内置 Image Gen 生成透明右翼，Sharp 仅缩放和编码，原图及完整提示词保存在源工程。
- 右翼在面板及原龙后方，保留原图龙首与恰好两只前爪；视口右边保留至少16px，900px以下隐藏新增外侧翼。
- 1440×960 分别检查页面宽度70%和92%；右侧留白减少时翼宽从423px收拢至277px。阅读框仍跟随原生宽度变量。
- 390×844、900×900、1440×960、2048×1152 未发现页面横向溢出；所有演示工具栏按钮中心仍命中对应按钮，装饰层 pointer-events 为 none。
- 手机角色抽屉可打开/关闭，边界为 x=12–378px；桌面阅读设置可以调整页面宽度并正常关闭。
- 菜单四角与银线在桌面、手机均可见；窄屏横排装饰缩至18px，没有挡住图标。
- `npm test`：15项通过；`npm run check`：通过。导出主题与工作台工程往返一致，五张图片均为内嵌WebP，无外部素材请求。
- 本轮核对本地 SillyTavern 1.19.0 / 06bde939f 的目标DOM；浏览器实测对象为独立演示。本次未更新已安装主题、未实测所有原生或第三方抽屉，也未测试实体手机。
