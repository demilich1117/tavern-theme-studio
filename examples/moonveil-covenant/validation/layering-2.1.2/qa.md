# 2.1.2 龙头层级验证

宿主：SillyTavern 1.19.0 / release / 06bde939f，本地http://127.0.0.1:8000。

## 根因与修复

实际DOM的#chat是#sheld的flex子项，计算层级30。龙图#sheld::before为10，银框为9。原生消息卡片滚动到顶部时，在30的聊天堆叠上下文中盖住龙头。原演示缺少宿主#chat的z-index:30，所以漏检。

源码直接设置#chat的z-index:0，使聊天内容（包括iframe和高层级消息按钮）整体位于银框和银龙下方。没有添加position:relative，避免激活宿主已有bottom:10px而导致聊天区上移。龙图及框仍pointer-events:none；原生菜单、输入区和第三方浮动控件没有改动。
