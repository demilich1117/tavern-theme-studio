# 2.0.6 桌面阅读空间验收

日期：2026-09-30。目标：SillyTavern 1.19.0 / release / 06bde939f。

## 改动

桌面默认整龙宽度由 `min(74vw,1040px,var(--sheldWidth,92vw))` 改为 `min(64vw,840px,var(--sheldWidth,92vw))`。框顶和聊天区顶部避让沿用现有公式，随整龙等比例缩小；原图与各媒体查询覆盖规则均未改变。

## 实际宿主

Chrome，2560×1215 CSS视口，用户原生页面宽度74%。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 龙图显示宽度 | 1040px | 840px |
| 聊天框顶部 | 280.31px | 228.72px |
| 聊天区顶部避让 | 130px | 105px |
| 聊天可见高度 | 658.50px | 735.09px |
| 输入区底边 | 1194px | 1194px |

阅读高度净增加76.59px，约11.6%。当前CSS与2.0.5按换行归一化比较后确认一致，再应用2.0.6，保留用户其他原生外观设置。通过原生更新主题按钮保存，未改动聊天内容或第三方悬浮控件。

实际宿主截图及前后尺寸只保存在项目 `output/playwright/desktop-space-*`，不随分发包提供。浏览器读取长文本可能截断；比较本轮主题时按片段读取完整DOM文本，避免将传输截断误判为用户修改。

## 演示回查

- 1440×960：框顶228.72px，聊天区496.91px高。
- 1001×900：框顶177.28px，聊天区513.27px高；桌面断点左侧边界正常。
- 1280×600：沿用短屏整龙450px规则，聊天区292.28px高。
- 393×852：仍为220px整龙、左右8px、框顶120.75px，手机布局保持原状。
- 所有测试尺寸输入区均在视口内，桌面龙图顶部未被裁切；主题导出回归测试通过。

`desktop-space.png` 是1440×960的干净演示截图，`desktop-space-layout.json` 是相应布局测量。手机与短屏本轮为独立演示回查，不宣称重新覆盖全部真实手机和第三方扩展行为。
