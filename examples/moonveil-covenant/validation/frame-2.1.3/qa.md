# 2.1.3 外框与顶部验证

目标宿主：SillyTavern 1.19.0 / release / 06bde939f。

## 外框位置

当前silver-frame.webp为400×400，中心竖线的上沿不透明像素落在y=35～49；32%切片为128px，78px的显示边段使内线落在29.86px处。此前伪元素top=-12px，可见内线比聊天区裁切边界低约17.86px，滚动正文会露在框顶上方。

将桌面外框top设为-30px，内线与聊天区顶部相差小于1px。只调整上沿偏移，边框尺寸78px、左右/下沿偏移-12px以及手机原有-8px规则保持原样；外框没有缩放或重绘。

## 真实宿主

实际酒馆2560×1271视口中，临时预览前后龙宽640px→600px，框顶-12px→-30px，聊天区991.70px→1006.02px。原生页面宽度保持92vw，输入区底部位置保持1251px；龙爪贴框，银线与聊天裁切边界对齐。记录在native.json。

采用独立工作台数据目录和仅包含CSS引用的临时工程；没有外观默认字段，因此不会重置原生页面宽度、字体比例或外观class。旧连接器的250 KB限制通过本地@import生产CSS进行临时验证，引用只存在于验证工程。分发主题仍内嵌7张WebP，没有外部URL或服务器依赖。

验证后关闭预览，原640px龙、-12px框顶、92vw宽度恢复，临时style和dock消失；连接器地址和抽屉状态恢复。真实截图仅保存在output/frame-2.1.3/native-evidence/，不进入分发包。没有编辑或发送聊天消息，也没有保存原生主题。

主题/工程往返、7张自包含WebP、原生RGBA颜色格式与JavaScript语法检查通过；压缩包清单的文件大小和SHA256一致。装饰pointer-events:none，聊天区没有横向溢出。未验证实体手机、软键盘、模型流式生成或主题保存持久化。
