# 2.0.5 图标对齐、背景清晰度与整龙缩小验收

日期：2026-09-30。宿主：本机 SillyTavern 1.19.0 / release / 06bde939f；Chrome 实际酒馆页面。

## 修改

- 菜单的 drawer、drawer-toggle 与图标覆盖相同区域，图标使用网格居中，去掉固定字宽与内边距造成的错位。
- 发送按钮桌面42×42px、手机34×34px，图案分别20×20px和18×18px并居中，保留宿主控制的显示状态。
- 手机取消局部轮廓裁切，完整原图缩小为 min(56vw,220px,48dvh)。393×852下，龙宽220px、框顶120.75px，左右各8px、框底840px。与2.0.4相比，聊天可用高度增加约57px。
- 背景从900×600改为原始1536×1024，WebP quality 72。其余三张主题图片保持原文件，不重绘用户定稿。
- 按用户最终要求，撤回悬浮控件避让规则；它们的位置及遮挡由各自插件管理。

## 验证

- 真实酒馆检查393×852、320×740、852×393、1440×960。阅读框与输入栏保持贴底，手机图标不换行；最窄屏阅读框左右各8px，横屏各12px。
- 菜单图标中心与按钮中心的横、纵偏差均为0。桌面抽查每项中心及四角共50个点均命中所属按钮。
- 悬浮球避让试验时393px手机50个点全部命中；最终按用户要求撤回这些规则，因此第三方悬浮控件仍可能遮住菜单，不能等同于主题图标自身偏移。切换设备时猫形控件也可能自行回到左上角，本版不干预。
- 用户设置抽屉可用键盘展开、收起；主题通过原生更新按钮保存。仅替换自定义CSS，保留用户74%的桌面页面宽度。
- 原生截图与诊断记录仅留在项目output/playwright，不随包分发。alignment-mobile.png和alignment-desktop.png为干净演示截图，供核对布局与素材。
- 主题导入、编辑、导出测试通过；JavaScript语法和连接器清单检查通过。基础主题CSS容量调整为1,000,000字符后，完整15项测试已通过；高级附加CSS限制仍为250,000字符。
- 四张主题图片共244,052 bytes；构建主题CSS为345,718字符。工作台当前工程文件SHA256保持不变。

浏览器设备模拟不等同于实体手机或软键盘测试。背景改善来自使用原图全尺寸，并非重绘或生成更高分辨率素材。
