## 已落实的反馈

- 巨龙位于界面的前后两层，龙爪扣住边框，接触投影与遮挡表达立体感。
- 头像框使用龙爪、鳞片和骨质环的手绘结构，装饰语言延伸到边角、滑块和输入区。
- 二维手绘超级英雄漫画语言：棱角形体、有粗细变化的轮廓线、硬边赛璐璐明暗；月白、冰青与紫罗兰，不使用黑红金。
- 删除装饰性主题大标题、口号、英文副标题和假拉丁文。保留功能标签、角色名和示例对话。
- 探索完整的菜单材质和控件造型，减少阅读区外围的空白。

## 后续实装必须处理

- 页面宽度接回 SillyTavern 原生 `--sheldWidth` / 用户设置滑块；不能继续由固定左右坐标让滑块失效。
- 取消过小的消息最大宽度与巨型外容器之间的空白，区分页面宽度和正文行长。
- 龙首、龙爪和装饰不得挡住文本、头像脸部、发送和设置操作；装饰层不接收点击。
- 宽度变化时，让前景龙爪跟随容器边界；窄屏降低装饰占比。
- 菜单位置与触发入口一致，原生折叠、拖动、滚动等行为以实际宿主验证。
- 概念图里的宽度滑块只是视觉表达，并不表示当前主题的宽度故障已修复。
