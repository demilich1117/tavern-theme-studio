# 夜幕浮雕设计约束

目标：SillyTavern 1.19.0 / release / 06bde939f；以 `concepts/relief-study/02-night-relief.png` 为选定视觉方向。

- 夜间西幻银龙，靛蓝与银灰、少量紫色；避免黑红金、科幻 HUD、照片或塑料3D。
- 二维手绘、鲜明剪影、棱角形体、深色粗细线、两到三组硬边赛璐璐阴影。
- 银龙跨上沿、侧爪挂右缘、龙爪围住头像。独立透明位图，不用整张概念图当网页截图。
- 阅读优先：20px桌面正文、17px手机正文；原生页面宽度可调，装饰只占边缘，滚动区固定避让龙首。
- 删除主题题名、口号、英文副标等装饰文字；只保留必要功能文字及角色内容。
- 原生功能仍属于酒馆，菜单不改成假控件。角色栏跟随左侧入口，复杂设置面板不强塞窄列。
- 主题从空白工程编写。1.0/1.1和早期视觉仅为历史记录，不是当前底层。
