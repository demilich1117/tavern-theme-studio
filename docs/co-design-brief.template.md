# 主题设计记录 · 由 Agent 维护

这是给 Agent 的记录模板，不是用户需要填写的问卷。用户只需说一句主题想法、主要设备和布局意愿，不确定的地方由 Agent 提案。Agent 从对话整理下面的内容，在本次主题源码目录维护 `design-brief.md`；尚无源码目录时先用 `output/co-design/<当前工程ID>/design-brief.md`。

随讨论更新同一份记录，当前用户选择优先于旧内容；换工程时更新路径并告知用户。交付或换对话时提供记录与参考图。不能写文件时直接给出可复制的记录，不声称已自动保存或同步到工作台。
