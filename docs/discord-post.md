# 酒馆主题工作台 · 在真实酒馆里边看边改 🛠️

整理了一个本地美化工具 **Tavern Theme Studio**。喜欢某套主题、但总想再改一点颜色、间距或字号时，可以直接在真实酒馆里试。

- **拾取元素 → 直接微调**：点击正文、头像等部件，改完马上看效果。
- **查看原样 / 撤销**：对比前后，不满意再退一步。
- **标点评论**：把想改的位置和意见留给 Agent，接着一起做。
- **保存定稿 / 导出主题**：作品单独保存，满意后应用到酒馆或分享 JSON。

从零开始也可以先和 Agent 聊想法、看方向，再来试样板。工作台提供预览和编辑工具，AI 对话仍在你自己的 Agent 里进行。

这次更新到 **0.11.1**，主要补充共创指南里的长文消息框适配、分块素材接口与自然融合规范。编辑器沿用 0.11 的功能。

**Windows 安装：**保持酒馆运行，下载 `core.zip`、完整解压，双击 `start.cmd` 并选择酒馆目录；连接器会自动准备。以后用 `update.cmd` 更新。
