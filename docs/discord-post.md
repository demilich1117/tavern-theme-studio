## 可复制正文

**喵喵美化工作台｜在真实酒馆里边看边改 🐾**

大家好，分享一个做酒馆美化的小工具：**喵喵美化工作台（Tavern Theme Studio）**。

它是一个在本机运行的开源主题工作台，可以一边看真实酒馆画面，一边调整主题。想微调现有美化，或和 Agent 一起从一个想法做出自己的主题，都可以用它来预览、修改和交付。

主要能做这些：

- **点选部件，直接微调**：拾取正文、头像等部件，调整字号、颜色、圆角和间距；也可以进入画布拖动位置、调整尺寸，改错了随时撤销。部件目录可以搜索，重叠部件也能选到。
- **用户和角色分开改**：分别调整双方的头像、名字和正文；整个推理块、图片、附件和表格也支持画布调整。
- **电脑、手机分开照顾**：同一页切换预览；尺寸覆盖说明能对照基础值、当前范围和实际画面，不用猜改到了哪里。
- **装饰贴得准，长文撑得开**：九宫格贴边和边距微调；九切片边框跟随消息容器，配合短消息、长文顶部／中段／底部检查。
- **和 Agent 一起迭代**：先聊想法、做样板，再回工作台微调。多个部件可以先排成蓝图，保存成一张修改小票交给 Agent；满意后保存定稿、应用到酒馆或下载主题 JSON。

两个小区别：**预览尺寸**决定怎么看，**应用范围**决定改哪些设备；**蓝图是待落实的方案**，保存小票不会直接写进导出的主题。AI 对话在自己的 Agent 里进行，工作台不会自动启动 AI。

**Windows 上手**：先启动酒馆，下载 `tavern-theme-studio-0.14.0-core.zip` 并完整解压，双击 `start.cmd` 选择酒馆目录，按引导打开工作台，就能开始试着调整一处字号或间距。
