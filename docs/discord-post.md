## 可复制正文

**喵喵美化工作台 0.14.0｜在真实酒馆里边看边改 🐾**

Tavern Theme Studio 换了个中文名，也来了两只小喵。装饰只放在标题和共创入口，编辑区继续留给你的主题。

这次主要把美化时常用的操作做顺手了：

- **直接拖，轻量调**：画布把手缩小，工具栏移到预览外；支持选择、平移、浏览、缩放和撤销。部件目录可以搜索，重叠部件也能选到。
- **用户和角色分开改**：用户头像、正文与角色头像、正文各有独立目标；整个推理块、图片、附件和表格也能接入画布。
- **电脑、手机分开照顾**：同一页切换预览；尺寸覆盖说明能对照基础值、当前范围和实际画面，不用猜改到了哪里。
- **装饰贴得准，长文撑得开**：九宫格贴边和边距微调；九切片边框跟随消息容器，配合短消息、长文顶部／中段／底部检查。
- **和 Agent 一起迭代**：先聊想法、做样板，再回工作台微调。多个部件可以先排成蓝图，保存成一张修改小票交给 Agent；满意后保存定稿、应用到酒馆或下载主题 JSON。

两个小区别：**预览尺寸**决定怎么看，**应用范围**决定改哪些设备；**蓝图是待落实的方案**，保存小票不会直接写进导出的主题。AI 对话在自己的 Agent 里进行，工作台不会自动启动 AI。

**Windows 安装**：先启动酒馆，下载 `tavern-theme-studio-0.14.0-core.zip` 并完整解压，双击 `start.cmd` 选择酒馆目录。已有安装可双击 `update.cmd` 更新；刷新前先保存未完成的蓝图。

## 发布配图顺序

1. `01-workspace.webp`：新版统一工作台。
2. `03-canvas.webp`：手机画布、推理块和外置工具栏。
3. `04-decoration.webp`：长文边框与装饰控制。
4. `06-export.webp`：原生主题应用与导出。

完整版视频按「想法与微调 → 画布选择 → 装饰与长文 → 蓝图与导出」组织；独立短片在 Release 的 `meow-studio-0.14.0-showcase.zip` 内，适合拆开发帖。旧版帖文已由本文替换，旧版演示链接保留在历史 Release。
