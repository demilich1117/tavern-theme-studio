# 控件设计与交付验收

## 制作

整体重设计按组件完成表面、文字、边界、图标与状态：按钮覆盖普通、悬停、按下、禁用、焦点；勾选覆盖未选、已选、禁用；输入区覆盖发送、生成停止、脚本暂停与继续。集中替换原有组件样式段，不在末尾反复叠补丁。

保留原生 DOM、事件、隐藏规则和图标字体。不要用全局 all:unset、强制 display、清空所有背景图或统一 font-family 消除宿主差异；先判断材质背景、语义图标和内容图片各自用途。主题颜色、圆角、阴影与层级数值属于作品，不作为工作台默认规则。

每轮先保存当前工程与源码恢复点，再读取用户覆盖。完成后用「保存 / 恢复版本」比较 rules、variableEdits、customCss、装饰和原生外观字段；列明本轮主动改变的项。源码同步保留微调不等于微调一定合理：负边距、固定宽度与定位冲突须结合真实消息验证。

## 工作台检查

「场景检查 → 检查当前画面」先等待字体、有限动画和布局稳定，再测横向溢出、裁切、可见控件的中心及角部命中；无限循环动画不会无限阻塞，超时标为待复查。控件报告不读取输入值和聊天正文，最多采样 60 个可见目标。

「检查控件状态」仅在空闲的原生测试对话运行。先打开需要检查的设置抽屉或弹窗；临时改变最多 12 个原生复选框的 checked / disabled，以及输入栏的原生显示状态，检查后恢复。不触发 input/change/click，不保存配置，不执行模型生成或脚本。输入未提交、消息正在编辑、脚本执行中或正在生成时拒绝运行；在预览中操作会取消并恢复。没有出现的控件明确跳过。

这属于外观状态复现，不能宣称真实停止生成、脚本执行或 TTS 播放通过。原生点击、空格勾选、焦点轮廓、滚动与折叠仍需实际操作。命中偏移不等于视觉偏移；复杂背景、透明混合、滤镜或无法解析的颜色不输出对比度通过结论。报告中的勾选比值仅用于明确的不透明底色与可见伪元素标记。

「样式诊断」补充背景图、滤镜、字体、display、position、z-index、原生勾选色及 RGB 通道；同时查看伪元素和命中采样。来源列表为候选声明，不声称完整层叠排名。原生选中颜色可能由导入时保存的通道派生，动态换色时必须检查最终计算值。

## 按变化选检查范围

| 改动 | 回归重点 |
| --- | --- |
| 颜色、字体、材质 | 浅深色、可用配色、勾选/禁用/焦点、图标字体、弹窗主操作与危险操作 |
| 输入区 | 空闲/生成/执行/暂停外观，按钮显隐、图标中心、点击命中，多行输入 |
| 面板与层级 | 原生抽屉开合和滚动，弹窗、实际点击与键盘，宿主断点两侧 |
| ST / TT 适配 | 非零安全区、输入焦点所在 surface 的键盘变量、顶栏堆叠上下文；分开记录浏览器契约与实机结果 |
| 导出与更新 | 原生导入、选中、保存、刷新，再切明暗和打开关键面板；导出一致性 |

截图前使用相同的稳定等待原则；只等待 jQuery 动画或固定 180ms 会漏掉 CSS transition。截图人工复核后才作为最终证据。几何通过、交互通过和视觉通过分别记录。

## 原生导入与发布

预览不会执行全部原生主题派生逻辑。发布前在隔离实例使用原生文件入口导入候选 JSON，选择主题，等保存完成后刷新，再切换明暗并检查弹窗、输入区与阅读布局。不覆盖日常实例的设置。

从同一工程修订导出 CSS、JSON、工程备份和配套扩展。比较 JSON.custom_css 与可读 CSS，核对所有版本、清单入口、压缩包文件名单、素材引用及原生字段；包内只收本次版本，不收用户截图、测试数据或历史草稿。安装说明区分「更新扩展」和「更新已保存主题 CSS」。这一步不会通过「场景检查」自动安装主题。

详细报告列明宿主版本、真实视口、主题模式、源码与工程修订、已执行状态和跳过项；可直接导出场景报告。TT 固定源码契约、真实 ST 和 TT WebView 实机分别标记。界面检查通过不意味着所有第三方自绘控件或消息 iframe 已兼容。
