## 真实宿主与录屏

使用独立 SillyTavern 1.19.0 和虚构 fixture，独立工作台与 dataRoot；以云间 1.0.5 为基础，演示素材只加入测试工程。没有发送聊天、调用模型或复制私人聊天。以下操作通过真实浏览器完成，字幕嵌在画面底部，未用模拟页面替代酒馆。

- 拾取角色正文并将字号改为 20px，读取计算值确认；撤销后切手机，仅手机范围设为 18px，检查尺寸覆盖说明并撤销。
- 画布拖动用户头像、撤销；目录搜索整个推理块并选中、调宽、撤销；浏览模式切换原生折叠。用户与角色目标的隔离同时由选择器与规则测试覆盖。
- 修复目录选择屏幕外部件无法聚焦的问题：定位允许找到屏幕外目标并滚入视口；实际拖动仍要求可见目标。录制中从聊天开头直接选择后面的推理块并成功调宽。
- 九宫格右上贴边，右侧留白 12px、顶部外悬 40px；九切片边框启用随容器伸展、整段铺满；检查用户长文顶部、中段、底部与手机视口。
- 手机蓝图连续调整角色头像与名字、保存整张修改小票；保存前后工程指纹相同，蓝图未写入实际主题。
- 使用新名称应用到测试酒馆，收到“已保存并应用”的原生回执；下载主题 JSON。没有覆盖用户现用主题。

截图、四段短片与完整版见 [演示素材](https://github.com/demilich1117/tavern-theme-studio/blob/master/docs/showcase.md)。短片介绍主要操作路线，不演示真实 Agent 执行过程。
