# 共创画布

在「从零共创」点 **打开共创画布**，或在编辑页点 **进入画布**。连接真实酒馆时会自动打开虚构测试对话，然后进入画布，不用先到工具里准备。准备中可以取消；有未提交输入或消息编辑时会保留内容并说明原因。未连接时可以在原有示例里试操作，示例不代表宿主兼容验证。

画布直接复用当前预览、部件拾取、右侧属性面板、编辑范围、工程规则、撤销和导出。不需要重新制作一份 HTML 或把微调抄到另一份工程。工作台和连接器需要一同更新。

若「进入画布」为灰色，按钮下会显示原因。连接器更新后需要刷新整个酒馆标签，再重新打开工作台；仅重新打开面板不会替换酒馆已加载的旧脚本。进入画布会自动退出「查看原样」。「更多工具 → 连接诊断」也会显示画布功能是否已加载。

编辑页分为「选择与调整」「反馈」「预览」：拾取、画布、标点评论、截图交接、测试内容定位和检查布局直接可见。布局与断点、高级 CSS、源码同步等低频操作放在有文字标签的「更多工具」，备份 / 恢复、保存定稿和应用 / 导出保留在页头。

## 实际布局

点击酒馆部件选择，或先用原来的拾取 / 对象列表选择。拖动 **✥** 调整上方和左侧外边距，拖动 **↘** 调整宽度与最小高度。方向键微调 1px，Shift + 方向键 10px；鼠标默认 8px 吸附，Alt 暂时关闭吸附。Esc 取消正在进行的操作，再按一次退出画布。手柄也可以用键盘聚焦操作。

- 修改作用于对应的同类部件，沿用「所有尺寸 / 仅手机 / 命名断点」。不会只改测试聊天中的某一条消息。
- 横向调整只改宽度；纵向调整只改最小高度。正文可以随内容继续长高。头像宽度按像素调整，其他部件默认按父容器比例。
- 外边距会参与真实排版，包括可能产生的挤压、留白或重叠；画布不自动改写 DOM，不保证任何拖动都能得到期望布局。
- 字号、圆角、颜色、宽度、外边距等仍在同一个属性面板编辑。像素 / 百分比宽度可以切换；单项还原沿用原来的还原按钮。
- 松开鼠标才保存，一次手势对应一次撤销。拖动过程中工程、目标或编辑范围变化时取消，不覆盖更新。旋转、三维变换或未命中的断点会提示改用提案或切换范围。
- 装饰沿用已有「可调装饰」工具。选择消息后可从属性面板的相关装饰入口打开，避免创建第二套图层数据。

「应用 / 导出 → 仅下载 CSS」导出当前主题 CSS（包含基础 CSS、部件调整和装饰，使用原有标准素材导出）。原生外观设置仍使用其中的主题 JSON 保存。摆放提案不会混入 CSS。

## 还原本轮

每次成功进入画布开始一轮。画布工具栏和编辑页都有 **还原本轮**，将本轮拖动 / 缩放涉及的位置、尺寸规则恢复到进入时；一次还原只占一条撤销记录，可以点「撤销」返回还原前，也可重做。

它不会重置整份主题，颜色、CSS 和其他属性修改保留。若同一属性后来在属性面板或其他来源被改成不同值，整轮还原会跳过它并提示保留数量。退出画布后仍可还原这一轮；重新进入则开始新一轮。同一服务会话内刷新工作台可保留本轮记录，关闭标签或重启工作台服务后不保证保留，请用原有备份 / 定稿作长期恢复点。

提案模式中的对应按钮是 **清除提案**：只清除当前临时虚线框，已保存的小票保留。

## 摆放提案

切换画布工具栏到 **摆放提案 · 交给 Agent**。拖动虚线框表达期望位置和尺寸，然后点 **评论此部件**，在原有评论窗口说明想法并保存。

虚线框表示布局意图，不会立即改变主题。小票保存原位置、期望矩形、所选部件、视口和工程快照，Agent 可以从同一小票 API 读取。这里的矩形坐标不是可直接粘贴的 CSS；跨容器重排、名字布局和特殊变换需要结合真实 DOM 落实。

保存后，编号标点继续使用原来的小票定位；同一工程指纹和相同视口下会额外显示提案虚线框。窗口尺寸或主题改变后隐藏旧框，保留小票中的原始数据供核对。未点「保存修改小票」的临时框会在退出画布、换部件或更新工程时清除。

## 截图与小票

画布工具栏的 **截取此标签** 调用浏览器标签捕获。请在浏览器弹窗选择当前酒馆标签；捕获一帧后立即停止共享。截图保留浏览器实际渲染，不使用 DOM 重绘模拟截图。浏览器不支持或拒绝时，可用系统截图，再在工作台 **截图交接** 中粘贴或选择图片。

截图交接窗口可选择当前工程的未完成小票，预览带评论摘要的 PNG，分别复制截图和完整交接文本，或下载 PNG 与小票 JSON。JSON 包含工程基线和布局提案；超长意见以完整文本 / JSON 为准。用户提供的系统截图无法自动验证拍摄时间，需自行核对画面和基线。

截图只保存在当前页面内存中，刷新或换作品前请下载。小票仍保存在原来的本机队列，不随关闭截图窗口丢失。复制不会启动 Agent，也不会自动发出消息。

## 导出前检查

在真实酒馆分别检查桌面和手机、长短消息、思考栏展开、多行输入、抽屉和消息操作。检查后用原来的场景检查、保存定稿、应用 / 导出流程交付。画布当前可见效果不等于所有状态都已经验证。

Agent 读取提案时应先核对小票基线；`canvas.kind = layout-intent` 的 `before` / `after` 表示原视口中的几何意图，不能当作已经生效的规则。实际布局调整则已存在于工程 `rules` 中，不需要再重复应用。
