# 共创画布

在「从零共创」点 **打开共创画布**，或在编辑页点 **进入画布**。连接真实酒馆时会自动打开虚构测试对话，然后进入画布，不用先到工具里准备。准备中可以取消；有未提交输入或消息编辑时会保留内容并说明原因。未连接时可以在原有示例里试操作，示例不代表宿主兼容验证。

画布直接复用当前预览、部件拾取、右侧属性面板、编辑范围、工程规则、撤销和导出。不需要重新制作一份 HTML 或把微调抄到另一份工程。工作台和连接器需要一同更新。

若「进入画布」为灰色，按钮下会显示原因。连接器更新后需要刷新整个酒馆标签，再重新打开工作台；仅重新打开面板不会替换酒馆已加载的旧脚本。进入画布会自动退出「查看原样」。「更多工具 → 连接诊断」也会显示画布功能是否已加载。

编辑页优先显示「选择与调整」和「部件与图层 / 属性」。标点评论、截图交接、测试内容定位和检查布局收在「场景检查与反馈」。布局与断点、高级 CSS、源码同步等低频操作放在「更多工具」，备份 / 恢复、保存定稿和应用 / 导出保留在页头。

## 选择与视图工具（0.14.0）

下列工具随 0.14.0 提供，需要工作台与连接器一起更新。

- **部件与图层**：可搜索、展开和收起原生部件目录。角色与用户分别导航；圆点表示当前编辑范围有覆盖。点击选取并定位，双击切到属性。画布选中另一对象时，目录清除旧搜索并展开它的祖先。装饰图层连接到原有显隐、锁定与叠放管理，不复制图层数据。目录顺序不改变原生 DOM。
- **选择（V）**：点击选取，悬停显示细虚线和部件名。外部路径可选父级；右键或「此处对象」（手机显示「内外层」）列出当前位置的已知部件。列表按部件类型去重，不把每条消息当作独立可编辑层。
- **平移（H）**：拖动画面移动工作台视图；空格可临时切换，松开恢复。不会改变部件外边距或写入工程。独立示例回退为聊天区滚动。
- **浏览（B）**：隐藏编辑把手，允许操作酒馆原生控件、滚动和选字。Esc 先返回选择工具；选择工具中 Esc 退出画布。
- **定位 / Shift+2**：将选中部件滚动到可见位置。**Shift+1** 适合窗口，**0** 恢复 100% 显示。这两项视图快捷键用于统一工作台，不改变真实视口宽度、断点或撤销记录。
- **?**：打开快捷键说明。快捷键限预览和画布工具区；输入框、下拉框、备注与弹窗保留原生输入。方向键微调仍在移动 / 尺寸把手聚焦时使用。

手机在预览外点击「部件」，搜索并选择后自动返回预览。详细属性继续使用「编辑」页。「所有尺寸 / 仅手机」是修改范围，工具栏和部件面板都会显示；它与顶部预览设备独立。

## 从进入到交付

1. 打开设计工作台，确认虚构测试对话，选择作品。顶部选预览尺寸，编辑区选修改范围，两者独立。
2. 确定要直接保存的微调用「实际布局」；想先试多个部件的位置，用「蓝图」。也可以只标点或直接与 Agent 讨论。
3. 蓝图连续调整后「保存整张蓝图」并填写整体意见，保存为一张小票；修改意见页自动选中新票。同一对话告诉 Agent「蓝图已保存」，首次或换 Agent 才复制交接。
4. Agent 核对快照、当前覆盖和每项范围后落实，验证桌面 / 手机与原生交互，回写待验收。
5. 检查实际工程效果，验收后保存定稿、应用或导出。蓝图草稿及小票本身不进入主题 CSS。

## 实际布局

### 抽屉与控件（0.15.0）

先切到「浏览」打开酒馆菜单，再切回「选择」，点击抽屉空白处或从「部件与图层」选择抽屉。生成设置、连接设置、高级格式、世界书、用户设置、背景、扩展、用户角色和角色管理均可分别调整。

- 抽屉移动使用距视口左侧 / 顶部的位置，缩放使用像素宽度 / 高度；属性面板可输入精确值、最大高度、留白、颜色与圆角。高度仍受最大高度约束，需随内容变化时还原高度。原生开关、滚动与最大化行为保留。
- 滑块轨道和复选框可直接拾取；滑块手柄、已勾选外框和勾选图案从目录或属性中的相关部件进入。每种修改只影响所在抽屉内同类控件。
- 手柄支持宽高、圆角、背景和边框；勾选图案支持宽高、颜色和对勾 / 圆点 / 方块 / 菱形 / 叉号。图案保持随原生勾选状态出现。这里编辑原生 range / checkbox，不替代第三方自绘控件或 Zen 模式的其他交互组件。
- 控件细节在属性面板中修改，不提供伪元素拖动把手；手柄选框表示所属滑块。Chromium 无法可靠读回手柄计算值，面板显示保存的覆盖并明确提示，需结合预览检查。
- 手机和电脑沿用独立范围、撤销和导出；抽屉也支持蓝图。抽屉位置和尺寸可通过「还原本轮」撤回；属性调整用单项还原或普通撤销。

以下聊天部件的移动和缩放仍沿用外边距与最小高度规则。

点击酒馆部件选择，或先用原来的拾取 / 对象列表选择。拖动选框左上的 **移动圆点（✥）** 调整上方和左侧外边距，拖动 **右下角缩放方点** 调整宽度与最小高度。方向键微调 1px，Shift + 方向键 10px；鼠标默认 8px 吸附，Alt 暂时关闭吸附。Esc 取消正在进行的操作，再按一次退出画布。手柄也可以用键盘聚焦操作。

当前源码采用细选框、18px 移动圆点和 10px 缩放方点，两者保留约 40px 屏幕点击范围与焦点提示，缩放预览时不会一起缩小。小部件和屏幕边缘的点击范围相互错开。进入画布时暂时收起已有评论标点，退出后恢复，避免标点挡住部件选取。此控件优化及下文的外置工具栏随 **0.14.0** 提供；旧 v0.13.0 安装包仍显示原来的大把手和内部工具栏。

- 修改作用于对应身份的同类部件，沿用「所有尺寸 / 仅手机 / 仅电脑 / 命名断点」。用户头像只影响用户头像，角色头像只影响角色头像；不会只改测试聊天中的某一条消息。主动选择“全部消息 · …”才同时调整双方，旧通用规则保留。身份拆分自 0.14.0 起提供。「仅电脑」首次使用时创建宽度不少于 768px 的断点；手机范围为不超过 767px。
- 横向调整只改宽度；普通正文纵向调整只改最小高度，仍可随内容继续长高。头像宽度按像素调整，其他部件默认按父容器比例。
- 整个推理块、消息内容组、图片与媒体区、附件区和表格现已接入画布（0.14.0）。这些容器可移动、调宽，**高度保持自动**；纯纵向缩放不会写入规则或撤销记录，避免折叠后留下空白或图片变形。推理块收起时点击标题优先选中整块；展开后的思考正文仍可单独选择，折叠栏可从目录或重叠对象列表选择。用户与角色的容器分别编辑。
- 外边距会参与真实排版，包括可能产生的挤压、留白或重叠；画布不自动改写 DOM，不保证任何拖动都能得到期望布局。
- 字号、圆角、颜色、宽度、外边距等仍在同一个属性面板编辑。像素 / 百分比宽度可以切换；单项还原沿用原来的还原按钮。
- 松开鼠标才保存，一次手势对应一次撤销。拖动过程中工程、目标或编辑范围变化时取消，不覆盖更新。旋转、三维变换或未命中的断点会提示改用提案或切换范围。
- 装饰沿用已有「可调装饰」工具。选择消息后可从属性面板的相关装饰入口打开，避免创建第二套图层数据。

「应用 / 导出 → 仅下载 CSS」导出当前主题 CSS（包含基础 CSS、部件调整和装饰，使用原有标准素材导出）。原生外观设置仍使用其中的主题 JSON 保存。摆放提案不会混入 CSS。

## 还原本轮

每次成功进入画布开始一轮。画布工具栏和编辑页都有 **还原本轮**，将本轮拖动 / 缩放涉及的位置、尺寸规则恢复到进入时；一次还原只占一条撤销记录，可以点「撤销」返回还原前，也可重做。

它不会重置整份主题，颜色、CSS 和其他属性修改保留。若同一属性后来在属性面板或其他来源被改成不同值，整轮还原会跳过它并提示保留数量。退出画布后仍可还原这一轮；重新进入则开始新一轮。同一服务会话内刷新工作台可保留本轮记录，关闭标签或重启工作台服务后不保证保留，请用原有备份 / 定稿作长期恢复点。

蓝图模式中的对应按钮是 **清空蓝图**：恢复当前尺寸的原生部件，清除临时摆放；可以撤销。已保存的小票保留。

## 电脑与手机分别预览

从 **设计工作台** 顶部切换手机 / 电脑，或自定真实视口尺寸。双击 `start.cmd` 或酒馆扩展中的「打开设计工作台」直达同一页；旧测试链接自动转入。桌面预览与编辑并排，窄屏切换「预览 / 编辑」。默认「适合窗口」仅缩放显示，不改变断点；精细操作可切到 100%，当前源码另有 50%–200% 的固定档位。编辑、素材、修改意见、共创和应用导出都在同一工作台内。

预览尺寸与编辑范围分别控制：看手机时请选「仅手机」，看电脑时选「仅电脑」；「所有尺寸」仍代表通用底层。范围未命中当前视口时会提示。原生窄屏 CSS 会按真实 iframe 宽度生效，但这不模拟实体手机的触摸、软键盘或浏览器差异。宿主限制嵌入或连接失败时显示准备状态和重新连接入口。

统一工作台的画布工具栏固定在真实酒馆预览外，当前部件、修改范围、蓝图数量及撤销 / 重做直接可见。手机切到「编辑」时收起工具栏，详细属性在同一编辑页调整。模式选择、评论 / 保存蓝图和退出直接可见；吸附、还原、截图及部件备注在 **更多操作** 中。窄屏或横屏展开后，工具区可以滚动，不盖在酒馆内容上。独立示例页保留内部工具条，其展开项仍叫「吸附、还原、截图与备注」。编辑页的撤销 / 重做和截图交接保持原有位置。

图层、选取和平移等后续改进的取舍见 [画布交互方案](canvas-ux-plan.md)，其中的建议不代表已实现功能。

## 多部件蓝图

切换画布工具栏到 **蓝图 · 多部件场景**。与实际布局一样，直接选择头像、名字、消息或输入区域，再用同一套把手移动、缩放；没有「加入选中部件」步骤。一次操作作用于当前编辑范围内、同一身份的同类部件，例如移动用户头像时，角色头像不跟着修改。名字也支持这套几何调整。用户头像和角色头像可分别记入同一张蓝图，不合并成一个目标。

换部件继续拖动会自动记入同一轮，最多记录 30 个「部件类型 + 编辑范围」组合，再点 **保存整张蓝图**，通过原有评论窗口一次保存整体意见。部件备注选填。「还原此类部件」只移除当前类型、当前范围的蓝图调整，「清空蓝图」恢复整轮。页头撤销 / 重做、画布快捷键及蓝图工具栏操作同一份草稿历史；退出蓝图后页头恢复工程历史。8px 吸附、Alt 取消吸附、方向键微调、Shift 步长和范围检查均复用实际布局。

蓝图用工程副本和实际布局相同的规则编译器预览，不保存工程 CSS，也不复制原件或导出聊天 DOM。退出、切回实际布局、切换预览尺寸或断开连接会恢复真实工程。尺寸草稿按工程与准确宽高分别保留在当前标签内存中，切回相同尺寸可继续；刷新或关闭页面前请保存小票。长文最小高度仍受原生内容限制，旋转和透视等不支持的状态沿用实际布局的限制。

主题在编辑过程中更新时，重新采集基线并把蓝图规则叠到当前主题，清空旧摆放撤销记录。已移除断点对应的草稿一同移除。同类规则会随原生消息重绘继续生效，无需重新加入节点。

小票记录整个场景的视口、各类部件的代表锚点、原位置、期望位置和备注，以及工程快照。新小票还包含 `appliesTo: matching-elements`、`scope` 和 `props`，明确同类联动范围与暂存规则；Agent 通过原有小票 API 读取。核对工程基线后再落实规则，避免把代表节点坐标误解为只改一条消息。旧版单部件与早期逐个摆放的小票继续可读。

## 截图与小票

画布工具栏的 **截取此标签** 调用浏览器标签捕获。请在浏览器弹窗选择当前酒馆标签；捕获一帧后立即停止共享。截图保留浏览器实际渲染，不使用 DOM 重绘模拟截图。浏览器不支持或拒绝时，可用系统截图，再在工作台 **截图交接** 中粘贴或选择图片。

截图交接窗口可选择当前工程的未完成小票，预览带评论摘要的 PNG，分别复制截图和完整交接文本，或下载 PNG 与小票 JSON。JSON 包含工程基线和布局提案；超长意见以完整文本 / JSON 为准。用户提供的系统截图无法自动验证拍摄时间，需自行核对画面和基线。

截图只保存在当前页面内存中，刷新或换作品前请下载。小票仍保存在原来的本机队列，不随关闭截图窗口丢失。复制不会启动 Agent，也不会自动发出消息。

## 导出前检查

在真实酒馆分别检查桌面和手机、长短消息、思考栏展开、多行输入、抽屉和消息操作。检查后用原来的场景检查、保存定稿、应用 / 导出流程交付。画布当前可见效果不等于所有状态都已经验证。

Agent 读取提案时应先核对小票基线；`canvas.kind = blueprint` 的 `items[]` 包含整张场景，各项 `before` / `after` 表示原视口中的几何意图。旧版 `layout-intent` 仍使用顶层矩形。这些不能当作已经生效的规则。实际布局调整则已存在于工程 `rules` 中，不需要再重复应用。
