# 0.12 本地候选验证

日期：2026-10-13。当前为发行候选，核心安装包尚未正式发布。

## 范围与结果

- SillyTavern 1.14–1.19 接口核对，以及 1.14 / 1.19 独立真实宿主的主题读取、测试样本、预览恢复和原生导入验收，详见[版本兼容](compatibility.md)。1.15–1.18 未跑完整浏览器流程。
- 全套 102 项 Node 测试通过，覆盖原有编辑 / 工程 / 构建 / 安装更新，以及新增后台鉴权、多个实例、单独与按安装目录关闭、动态作品切换、排队保存、锁释放、旧记录异常处理和卸载保留范围。
- 后台 HTTP 接口拒绝错误令牌、外部 Origin、实例身份不符的服务。无法核验时不按 PID 强杀；另一个程序目录的后台在卸载范围之外。
- 临时安装包解压验证：包含管理 / 关闭 / 卸载入口，首次安装、重复启动复用、Windows PowerShell 关闭后台、保存与重启、卸载预览和实际卸载；实际卸载时仍运行的手动后台须先关闭。酒馆设置、其他扩展、作品和自定义文件保留。
- 浏览器使用两个临时作品和隔离登记目录；验证顶部入口、两个实例列表、单独关闭、修改保存、关闭剩余实例、页面停止编辑。两个测试服务均正常退出，登记清空，两个作品锁均释放，保存名称仍在工程文件中。
- 1280 / 1024 / 768 / 390 像素宽度检查无页面横向溢出。桌面及手机截图保存在开发目录 `output/playwright/runtime-manager-*.png`，不随程序分发。
- 26 个服务模块归入 `src/`，根目录保留兼容启动入口；同步更新导入、内置主题构建脚本、程序根目录、打包和卸载清单。整理后重新通过全部 102 项测试与核心包启动 / 构建相关测试 / 后台关闭 / 卸载验证，没有把数据位置迁入 `src/`。

## 边界

旧进程无法动态获得新版管理接口；旧手动后台的发现范围和处理方式见[后台管理与卸载](backgrounds-uninstall.md)。测试没有关闭用户原有后台、没有卸载实际连接器，也没有发送真实模型请求。卸载针对程序文件及安装记录，保留 `.local`、作品和本地改动，不声称擦除全部数据。
