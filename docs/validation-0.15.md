# 0.15.0 抽屉与控件编辑验证

日期：2026-10-15。

## 实现范围

- 九类原生抽屉独立选择、视口坐标移动、像素宽高和最大高度调整。普通聊天部件仍使用外边距与最小高度。
- 各抽屉独立的 range 轨道、滑块手柄、checkbox 外框、选中外框和勾选图案。手柄和伪元素由属性编辑，目录及相关部件可定位。
- 勾选图案提供对勾、圆点、方块、菱形、叉号；不改变 checked 状态。手柄 WebKit / Firefox 规则分别输出，避免不支持的伪元素使整组选择器失效。
- 几何规则排除原生 maximized 状态；最大化时禁止画布拖动。普通外观覆盖继续生效。
- 原生抽屉和控件选择器根据本地 SillyTavern 1.19.0 源码核对。

## 浏览器实测

独立 SillyTavern 1.19.0、独立 dataRoot、独立工作台工程、虚构测试对话，Chromium 桌面浏览器；未调用模型或接触私人聊天。

- 属性面板将用户设置抽屉设为左 80、上 70、宽 620、高 650px，读回实际矩形一致。
- 画布移动及缩放把手的方向键操作生效；移动后撤销恢复原坐标。
- 仅手机范围设为左 12、上 48、宽 366、高 700px，在 390 × 844 视口读回一致；切回 1440 × 900 后恢复桌面位置与尺寸。
- 手柄设置 24 × 24px、4px 圆角、金黄色，截图检查；Chromium 不提供可靠的手柄计算样式，界面明确标注，不用 input 的计算值冒充手柄尺寸。
- 勾选图案设置为 12 × 12px 金色菱形，读回伪元素尺寸、颜色及 clip-path 一致；另一个抽屉未被改色。
- 浏览模式下原生抽屉可关闭并重新打开，尺寸保持；重启工作台并刷新测试标签，控件和手机覆盖仍存在。
- 截图保存在本地 `output/playwright/drawer-desktop.png` 和 `drawer-phone.png`，不打包个人测试工程。
