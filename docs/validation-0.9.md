# 0.9.0 素材与装饰清点验证

日期：2026-10-09。真实宿主为 SillyTavern 1.19.0 / 06bde939f，工作台及连接器 0.9.0，Node 22.19.0。主酒馆 8000、主工作台 19323；主题切换验证使用独立工作台 19324，不切换主工程。每次读取聊天画面或截图前确认 `#fixture-status` 为「当前为虚构测试对话」。没有发送消息、调用付费模型、验收历史小票、修改 Source Hub 或推送发布。

## 实现范围

按用户最后的选择，主流程为“先清点图片与装饰 → Agent 分析用途、整理素材库 → 按需接入图层”。扫描是只读操作，没有自动猜测或生成图层。

- 当前工程 CSS、变量编辑、生成规则、高级 CSS 和显式图层素材统一清点；图片按引用归并，保留多处使用位置。
- 包括转义 URL、image-set 字符串、多重背景、图片边框、蒙版、content 图片、伪元素、渐变/阴影和变量关联。字体与外部样式表单列类型。
- 无法解析、动态值、循环变量、外部 @import 和相对引用保留说明；变量关联不冒充最终层叠。
- UI 搜索、分页、按需素材预览、外链登记、下载清单；已有配方提供的中文用途用于展示，未改素材库原始命名。
- 复制交接冻结快照，CLI 导出原文/有效基础 CSS、生成 CSS、高级 CSS、最终 CSS、工程结构、清单及哈希校验后的本地图片。
- 从原生酒馆读取新主题前显示名称，确认后保存旧工程快照、建立新工程、暂停旧源码自动同步；支持撤销恢复。

## 边界

本轮手机是 Chromium 视口模拟，实体手机与其他浏览器未验证。外部 @import 没有展开，运行时 DOM、第三方扩展样式、聊天图片不属于静态扫描范围；未知项不代表不存在。图像内容识别、用途命名与图层接入由 Agent 后续处理；没有宣称任意主题可自动还原全部图层。流式、群聊、厂商 CLI 自动启动和完整原生主题导入没有在本轮重复验证，沿用既有记录中的实际边界。
