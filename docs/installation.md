# 酒馆主题工作台 · 核心安装包

「作品」入口支持继续编辑、保存定稿、下载历史主题及打开文件夹。已有作品可整理为独立目录，升级时保留完整作品；见 [固定作品目录](work-folders.md)。

在真实酒馆里调整颜色、圆角、间距和装饰，满意后直接应用到酒馆，或下载主题 JSON 分享。本包版本 **0.12.0**；连接器适配 **SillyTavern 1.14 起**，已核对 1.14–1.19，实测范围与限制见[版本兼容](compatibility.md)。

**Windows 双击 `start.cmd` 安装并启动，双击 `update.cmd` 更新并启动。** 首次选择一次酒馆目录，连接器、缺少的运行环境和依赖自动准备。详见 [一键安装与更新](install-update.md)。编辑仍用原来的拾取与属性面板，见 [直接编辑指南](direct-editing.md)。

找不到运行窗口时，双击 `manage.cmd` 查看占用作品的后台，`stop.cmd` 关闭全部；界面顶部也有「后台管理」。需要移除工具时双击 `uninstall.cmd`，作品和备份会保留，详见[后台管理与卸载](backgrounds-uninstall.md)。

服务代码已集中到 `src/`，日常只需上述五个入口；目录用途与数据保留位置见[文件夹说明](project-layout.md)。

运行依赖和连接器 ZIP 已包含在包里。入门与进阶是同一个工作台的两种路线。

## 普通用户入门

### 1. 启动

保持酒馆运行，完整解压本包，进入 `tavern-theme-studio` 文件夹。Windows 双击 `start.cmd`；首次弹出选择框时选 SillyTavern 文件夹（含 `server.js`），之后会记住位置。多用户酒馆再选择一次当前用户。

macOS / Linux 准备 Node.js 22+ 后，在此目录运行：

```powershell
npm run setup
```

运行期间保持终端开启。

### 2. 连接器自动就绪

启动器已自动安装或更新连接器，并打开专用测试页，无需手工复制。只有手动部署时才需要解压 `dist/tavern-theme-studio-connector.zip`，将整个连接器文件夹放入酒馆 `data/<用户名>/extensions/`。

正确层级：

```text
data/<用户名>/extensions/tavern-theme-studio-connector/
├─ manifest.json
├─ connector/
└─ shared/
```

刷新或新开酒馆标签，在「扩展」面板确认出现「主题工作台」。不要多套一层同名目录。

### 3. 打开测试对话

自动打开测试页后，等工作台显示「当前为虚构测试对话」；浏览器没有自动打开时用终端打印的 `#tts-lab` 链接。默认工作台端口是 19323；酒馆地址从所选目录配置读取，特殊地址的设置见 [一键安装与更新](install-update.md)。

### 4. 改一处样式

在「作品」选择已有作品，或「新建作品」接入当前主题、导入 JSON。「从空白开始」只需填写名称，会自动准备源码与同步。各件作品独立保存。

点「拾取元素」，再点击消息正文、头像等目标部件；想改整块消息背景，可在「选择编辑对象」选择「角色消息」。调整颜色、圆角或间距，数值可直接输入，透明度和四边间距按需展开。

勾选「查看原样」比较前后，`Ctrl+Z` 撤销。规则作用于同类部件；窄屏修改用「仅手机」，检查时缩窄真实酒馆窗口。手机默认半屏面板，拖动顶边可调高度。平时自动保存；大改前也可在「备份 → 保存 / 恢复版本」留快照。

### 5. 应用到酒馆，或下载分享

点击「应用 / 导出」，确认新名称，再点「应用到酒馆」。如有酒馆导入提示，按提示完成；等「已保存并应用」后，关闭工作台也会保留效果。

需要分享或没有直接应用入口时，点「下载酒馆主题 JSON」，再到酒馆「用户设置 → UI Theme」导入并选择。遇到同名提示时换一个新名称。

**临时预览和自动保存草稿不会更改酒馆保存的主题。** 应用成功后才会持久生效，后续微调不会自动覆盖已应用版本。普通导出和直接应用会内嵌本地图片，保留原有图片、字体外链；含外链的主题仍需网络。

### 6. 保留工程

下次从「作品」选择已有作品继续编辑；平时自动保存，满意时「保存定稿」。从「备份 → 下载工程备份」保存的 `.studio.json` 包含当前工程与本地素材，不含完整历史和源码；完整迁移请保留整个作品目录，见 [固定作品目录](work-folders.md)。

## 从零制作自己的美化

先直接和 Agent 聊一句想法，例如「暗黑童话，手机为主，布局可以大改」，不必为了讨论先装工具或填表。已有工作台时，「从零共创 → 复制给 Agent，开始共创」可以把工程信息一起带入对话；参考与特别要求选填。Agent 负责记录选择和阶段衔接。

Agent 先认识酒馆部件，用构图和排版不同的图与你讨论；大方向敲定后，先做可试用样板并接入真实工作台。你可用「拾取元素」自行微调，或「标点评论」后告诉当前 Agent 已标好，让它继续改。满意后点「应用到酒馆」。复制不会启动 AI，参考图片需另附。

起步想法按工程留在此浏览器，需要时展开「想法怎么保存？」下载。Agent 维护的设计记录随主题交付，不会自动同步回工作台；换对话时带上它和参考图即可。界面地图、工程起点、出图与验收规范见 [完整共创指南](co-design.md)。已有明确参考图或只做小修，可以缩短探索。

允许大改时，概念图可以大胆重构布局。选图后，Agent 尽量照图制作头像、消息和阅读区，用真实截图比较后给你试样板；有具体限制时说明差异与替代。

[看 DOUBLECHEESE 六格共创漫画与文字步骤](comic-guide.md#page-3)。

漫画保留 0.9.2 的画面与手动导入流程；0.10 的入口与直接应用方式以本说明和漫画旁的文字为准。

## 进阶路线

| 需要什么 | 使用方式 |
| --- | --- |
| 接入另一份主题 | 「作品 → 新建作品」，接入当前主题或导入 JSON；已有作品直接选择打开 |
| 找到图片与装饰 | 「素材 → 主题图片」清点使用位置，再整理素材库和图层 |
| 让 Agent 修改指定位置 | 标点写需求 → 复制小票 → 粘贴到已打开本项目的 Agent → 检查后验收 |
| 调整复杂样式 | 「主题样式」「高级 CSS」、断点和样式诊断 |
| 完整备份或严格导出 | [进阶指南的交付与备份](advanced-guide.md#delivery) |

复制小票不会自动启动 AI。工作台没有内置模型聊天面板；Source Hub 和本机 CLI 适配都按需配置。

## 启动、升级和故障处理

`npm start`、`npm run lab` 和 `start.cmd` 使用记住的作品目录；尚未选择作品时沿用 `.local/native-lab/`。高级独立模式为 `npm run start:standalone`（19321 / `.local/`）。同一数据目录只运行一个实例。

`STUDIO_PORT`、`STUDIO_DATA_DIR`、`TAVERN_URL` 分别设置工作台端口、数据目录和酒馆地址。升级前停止工作台，备份并保留完整作品目录和工具的 `.local/`（含作品位置记录与未迁移的工程）；设置过自定义数据目录时也要保留它。

日常更新双击 `update.cmd`，程序校验与备份、连接器同步、重新启动和打开测试页会自动完成。作品和配置保留；程序存在本地改动时会停止覆盖。从旧版首次迁入需关闭旧启动窗口，保留数据后放入新版，再运行 `start.cmd`。换安装目录时按 [固定作品目录](work-folders.md) 恢复位置。

连接或启动问题先运行 `npm run doctor`，再看「高级工具 → 连接诊断 → 检查连接与版本」。检查依赖是否完整、连接器目录层级是否正确、酒馆与工作台是否仍在运行。
