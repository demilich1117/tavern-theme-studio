# 0.11 一键安装与更新验证

环境：2026-10-11，Windows，Node 22+，Windows PowerShell 5.1。安装目录依据本机 SillyTavern 1.19.0 / 06bde939f 的 `config.yaml`、用户数据目录与扩展加载结构核对。个人酒馆、聊天、作品和已安装连接器未替换。

新增测试覆盖：

- 首次安装、重复安装、记住自定义数据目录、多用户选择与连接器增量更新；用户设置及其他扩展文件保留。
- 写入失败恢复、进程中断后的事务恢复、恢复前检测后来新增的修改；拒绝路径越界、重名与目录链接。
- 正式版下载地址、SHA-256、ZIP 结构及每个清单文件校验；拒绝损坏包、数据目录文件、缺失附件和版本降级。
- 核心包更新保留 `.local/` 和清单外文件，只移除旧版本明确列出的废弃程序文件；本地源码修改时停止覆盖。
- 自动关闭接口的认证、持久化后释放锁、旧版手动启动实例的保护。
- Windows PowerShell 使用固定的本地下载响应测试便携 Node 的校验、解压、启动、复用和损坏下载拒绝。测试包含实际 Node 可执行文件，没有调用系统安装器。

全套发布检查包含 87 项测试；非 Windows 平台跳过 PowerShell 专项。核心包重新解压到临时目录，验证启动、编辑命令、导出和重启；另外运行包内安装入口，确认连接器安装、记住路径、重复启动复用同一服务及自动关闭。Windows 使用包内 PowerShell 启动入口执行，测试禁止打开浏览器，宿主只提供隔离的安装目录。

实现提交 `9d13471` 的 [远端发布检查](https://github.com/demilich1117/tavern-theme-studio/actions/runs/38133309389) 已通过，覆盖 Windows / Linux 和 Node 22 / 24。

开发期间，本机访问 Node 官方站点的实时下载出现 TLS 连接中断，未将它记为下载成功。固定响应测试验证了处理逻辑，实际首次联网下载仍取决于用户网络；已有 Node 22+ 的路径不需要下载运行环境。在线新版核心包使用固定的正式发行响应验证，未将它记为公开在线升级。ARM64 真机、macOS / Linux 实机和目录选择对话框的人工点击未验证。此前的原生主题编辑与应用验证见 [0.10 记录](validation-0.10.md)。
