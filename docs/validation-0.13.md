## 本轮真实浏览器

使用项目内 SillyTavern **1.19.0** 副本、新建独立数据目录和虚构测试对话。Chrome **1440 × 1000** 与 **390 × 844**；手机 / 电脑宿主视口分别为 **390 × 844**、**1440 × 900**。内置浏览器的尺寸覆盖未生效，尺寸验证改用独立 Chrome 测试标签。

1. **统一入口 → 作品 → 编辑：通过。** 准备后显示虚构测试状态；桌面预览与编辑并排，窄屏切换预览 / 编辑，进入画布自动回到预览。
2. **蓝图调整：通过。** 轻量工具条显示当前部件、范围与蓝图数量；无需展开更多操作即可撤销 / 重做。仅手机范围下，10 个头像一起移动，名字另记一项；电脑尺寸草稿独立，切回手机恢复原来的两类部件。
3. **保存 → 交接：通过。** 两类部件保存为一张小票，自动显示修改意见并选中新票；真实剪贴板交接包含 `items[]`、`scope`、`props`、`matching-elements`、重新读取快照的要求。API 核对每项范围与规则，工程指纹与蓝图操作前一致。
4. **退出 → 应用：通过。** 退出恢复全部头像的原外边距。发现并修复属性面板保留旧蓝图计算值的问题；复测名字上方外边距从蓝图的 10px 恢复为工程的 0px。通过统一工作台把候选主题保存并应用到隔离酒馆，控制台无错误。

本轮日志、截图和流程报告保存于本机 `output/flow-release/`，不打入发行包。测试使用独立工作台；结束后关闭本次测试进程、释放作品锁并恢复测试宿主原连接器。没有发送消息或调用模型，也没有改用户的主题作品。

## 手机界面的取舍与边界

保留预览 / 编辑切换，以轻量画布工具条承接部件、范围、蓝图状态和撤销操作；详细属性仍在原编辑页。没有恢复常驻半屏表单，避免进一步压缩预览。蓝图未保存前仍只在当前标签内存中；保存小票不等于已写入主题，应用 / 导出不包含临时蓝图。

本轮检查包含可见标签、键盘方向键、撤销 / 重做及窄屏布局，不代表完整无障碍认证。实体手机触摸、软键盘、Safari / Firefox、第三方扩展组合、真实流式与群聊未实测；最低版本仍是 1.14，跨版本依据与历史验证见 [兼容记录](compatibility.md)。
