# 喵喵美化工作台 0.15.1

本版把 ST / TT 双宿主主题制作规范纳入共创流程和核心安装包，同时发布 0.15 系列的抽屉与原生控件编辑能力。

## 更新内容

- 后续美化默认尽量兼顾 SillyTavern 和 TauriTavern。共创入口、宿主参考、原生测试指南与 Agent skill 统一指向双宿主适配指南。
- 新指南说明 TT 的移动断点、安全区、软键盘、宿主布局优先级、消息虚拟化及配套扩展版本检查，并区分源码核对、浏览器复现和真实 WebView 验证。
- 沿用 0.15.0 的九类原生抽屉位置、宽高和最大高度编辑，以及各抽屉的滑块轨道 / 手柄、复选框和勾选图案样式；支持手机 / 电脑范围、撤销及导出。
- 核心包包含上述指南，独立安装也能读取固定 TT 提交的参考链接。

## 安装与更新

下载本页的 `tavern-theme-studio-0.15.1-core.zip`，完整解压后双击 `start.cmd`。同名 `.sha256` 文件用于校验；GitHub 自动生成的 Source code 包不是核心安装包。

已有安装双击 `update.cmd`，启动器同步更新连接器。升级前保存未提交的蓝图小票，保留完整作品目录和 `.local/`；更新后刷新工作台与专用测试标签。Git 源码安装通过快进合并更新。

## 验证范围

发布检查使用 `npm run release:check`：语法与版本一致性、Node 测试、核心包和连接器打包、干净目录启动 / 命令 / 导出 / 重启、一键安装及卸载保留数据。具体提交的 Windows / Linux、Node 22 / 24 结果见 [GitHub Actions](https://github.com/demilich1117/tavern-theme-studio/actions/workflows/ci.yml)。

抽屉与控件的 SillyTavern 1.19.0 浏览器实测记录见 [0.15.0 验证](../validation-0.15.md)。本补丁新增内容为制作规范与分发更新，没有重新声明其他宿主的运行验证结果。

TT 参考固定于 2.3.0 源码提交 `f6126b4fc9243eb3990f2c0bad86e2afcb502f22`，兼容 ST 1.18.0；不代表用户安装版本或最新发布版。工作台自动安装器、连接器、测试聊天写入流程及真实 TT WebView / 原生键盘尚未完成实机验证。主题制作的双宿主目标不等于工作台已获得完整 TT 运行支持。
