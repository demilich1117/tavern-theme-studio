# 喵喵美化工作台 0.16.0

本版将控件与面板修复中的通用检查加入工作台，保留现有拾取、微调和快照流程。

- 场景检查等待字体、有限动画及布局稳定，超时明确提示；增加可见控件遮挡采样、停止图标中心和可计算的勾选对比度检查。
- 新增「检查控件状态」：仅在空闲专用测试对话，临时检查勾选/未选/禁用与发送/停止/暂停/继续外观，结束或取消后恢复。不调用模型、不保存设置。
- 样式诊断补充背景图、滤镜、字体、层级、原生勾选变量、伪元素和命中信息。
- 新增[控件设计与交付验收指南](../control-validation.md)：组件完整状态、保留用户微调、原生导入刷新、ST/TT 分层验证和同源发布检查。

下载 `tavern-theme-studio-0.16.0-core.zip`，完整解压后双击 `start.cmd`；已有安装使用 `update.cmd`。同步更新连接器并刷新专用测试标签。保留作品目录与 `.local/`，先保存未提交蓝图。

本地发布检查和真实 ST 浏览器验证见[0.16 验证记录](../validation-0.16.md)。对应提交的 Windows / Linux、Node 22 / 24 检查见 [GitHub Actions](https://github.com/demilich1117/tavern-theme-studio/actions/workflows/ci.yml)。

检查报告不读取输入值和聊天正文；状态复现不能代替真实模型生成、脚本执行或键盘操作验收。复杂背景的对比度需人工核查。TT WebView、原生键盘与全部第三方自绘界面仍未宣称实机覆盖。
