# 喵喵美化工作台 0.14.0

Tavern Theme Studio 的中文名更新为「喵喵美化工作台」，两张轻量透明猫咪插画点缀标题与共创入口。

本版把近期的画布与酒馆构筑改进一起交付：

- 更小的移动／缩放把手，预览外的工具栏；选择、平移、浏览、缩放、定位与快捷键。
- 可搜索的部件目录、父子路径与重叠对象选择；选择屏幕外部件会自动定位。
- 用户与角色的头像、名字、正文等目标独立，避免修改用户部件时角色也跟着改变。旧版共同规则保持原意。
- 整个推理块、消息内容组、媒体、附件与表格接入画布；这类容器调宽时保持自动高度。
- 尺寸覆盖说明、九宫格装饰贴边和离边距离；九切片消息边框随容器伸展，支持用户／角色的短消息及长文分段检查。
- 更新入门、画布、装饰教程；提供 6 张实际截图、4 段中文字幕短片和完整流程演示。

## 下载

- `tavern-theme-studio-0.14.0-core.zip`：完整核心安装包，含运行依赖和新版连接器；旁边的 `.sha256` 可用于校验。
- `meow-studio-0.14.0-demo.mp4`：完整流程演示，字幕已嵌入画面，无需另加载字幕。
- `meow-studio-0.14.0-showcase.zip`：6 张原始截图、4 段短片、Discord 文案和两张猫咪透明原图／WebP。

Windows 完整解压后双击 `start.cmd`；已有安装可双击 `update.cmd`。工作台与连接器需同步更新，刷新前先保存蓝图小票。保留 `.local/` 及独立作品目录。GitHub 自动生成的 Source code 压缩包不等于核心安装包。

预览尺寸决定怎么看，编辑范围决定改哪些设备。蓝图仍是待 Agent 落实的方案，保存小票不会写入正式主题；导出只包含已保存的实际修改。

本轮实录使用 SillyTavern 1.19.0 的隔离虚构测试对话；手机效果为浏览器视口模拟。125 项测试、本地发布检查及此提交的 Windows / Linux × Node 22 / 24 CI 通过后发布。详细范围见 [验证记录](https://github.com/demilich1117/tavern-theme-studio/blob/v0.14.0/docs/validation-0.14.md)。
