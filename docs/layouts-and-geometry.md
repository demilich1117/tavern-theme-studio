# 画面定位与布局（0.7）

在「装饰图层」选中可定位、未锁定且可见的图层，选择尺寸，点击「在真实画面定位」。面板暂时隐藏，真实宿主显示装饰框、容器坐标参考、锚点与等比缩放手柄。拖动中只有临时 CSS，松手保存一次；方向键每次 1 个 CSS px，Shift 为 10px。Esc 取消当前手势；再次 Esc 或「返回工作台」结束定位。

定位用临时不可见校准节点测量浏览器实际包含块和装饰四角，记录容器 CSS 坐标，支持滚动、二维旋转、缩放与 CSS zoom。校准节点立即移除，导出不依赖它们。不可逆变换、非线性透视、源码已有未声明的独立 translate、占用插槽或当前不命中的尺寸会提示处理，不保存看似有效的截图坐标。相同选择器有多个目标时代表一个可见实例，CSS 编辑作用于该插槽全部匹配。

拖动时容器实际移动、变换或被替换，会取消当前手势；其他普通重绘继续预览。服务基线变化也会取消，提交核对 projectId/sessionId/fingerprint/revision。触摸在编辑覆盖层里拖动，不滚动宿主；覆盖层外保留宿主操作。浏览器 resize、滚动、重绘与关闭重连更新/清理覆盖层。触摸采用 Chrome 模拟验证，实体手机未测。

「布局与断点」提供阅读面板、聊天、输入区域、左右侧栏与正文容器的 Flex/Grid、宽度上限、留白与间距。只改 CSS，不添加 order 或反向排列，不重排原生 DOM。旧 mobile 固定 `(max-width: 767px)`；可新建命名 min/max-width，或从配方建立真实条件。月弧浮页使用 1000px/1001px；重叠条件按列表顺序覆盖。删除断点同时删除其部件和图层覆盖，可整体撤销。

HTTP/CLI 仍走完整写入基线与 `command`：

```json
{"type":"breakpoints","breakpoints":[{"id":"mobile","name":"仅手机","condition":"(max-width: 767px)"},{"id":"tablet","name":"平板","condition":"(max-width: 1000px)"}]}
```

布局使用既有 `set` 命令，例如 `target:stage, property:max-width, value:90vw`，或 `target:composer, property:gap, value:8px`。尺寸与枚举受限，禁止声明注入和在原生输入等非容器上改变布局。图层定位新增桥接能力 `decorationEditor:1`，只有新连接器开放定位入口。

停靠面板左边缘可拖动调宽；键盘聚焦分隔条后，左右键 10px，Shift 50px。宽度限制 320–900px，并受视口上限约束；收起/展开保持本次宽度，关闭清理监听。
