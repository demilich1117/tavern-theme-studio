# 0.9.2 操作简化与导出恢复验证

日期：2026-10-09。用户授权执行界面与流程优化。操作简化阶段的起点为本地提交 `71b8d18`，保留原有实现、工程和历史小票。真实宿主为 SillyTavern 1.19.0 / 06bde939f；工作台与连接器升级为 0.9.2，工程仍为 schema v3。以下原始记录保留当时未发布的状态；后续共创增补与首次发布准备见文末。

## 改动

- 主入口收敛为「编辑 / 素材 / 修改意见」。素材下分主题图片、素材库和可调装饰，使用同一工作区切换，避免连续弹窗。
- 编辑优先显示字号、行高、圆角和留白。CSS 选择器、几何诊断、来源声明折叠；源码绑定、测试工具、布局和高级 CSS 集中到工具入口。主题变量使用源码中的说明作为标题，保留条件和原始声明供展开查看。
- 图片先展示缩略图与可操作状态。尚未接入的图片可单独「让 AI 接入」，复制冻结快照及该图片全部引用位置；复制不启动 Agent，也不自动产生可拖动图层。
- 修改意见默认只列当前工程；用户可切换全部工程历史。简明复制为主操作，结构化数据保留在详情中。
- 普通主题导出内嵌工作台本地素材，保留原有公开图片与字体外链；拒绝本机外链。离线和固定外链校验仍单独提供。导出名称默认追加时间，可修改，避免原生导入器拒绝同名主题；下载后提示原生导入并选择新主题。
- 主题文件、工程文件、宿主主题接入、替换底层主题、分文件恢复和快照恢复，均在替换前持久保存恢复快照。快照保存失败则中止替换，重启后仍可恢复。
- `start.cmd`、`npm start`、`npm run lab` 与连接器默认统一到 19323、`.local/native-lab/`；CLI 优先发现相同服务。重复启动核对目录锁、运行信息及服务返回的数据目录后复用。高级独立启动仍用 `npm run start:standalone`。
- 修复素材与小票切换时误删另一模块错误节点导致扫描停留的问题，以及 CLI 任务成功与「已验证」状态分两次发布的竞态。

## 限制

手机检查是 Chromium 视口模拟，未验证实体手机、软键盘和跨浏览器行为。本轮不新增发送、群聊、真实流式、第三方组件或厂商 CLI 验证；没有调用模型。图片交接检查覆盖复制内容和 UI，不代表 Agent 已自动完成图片接入。复杂伪元素和纯 CSS 装饰仍需 Agent 理解后显式接入，不能承诺任意主题导入即全部可拖动。

普通导出允许保留外链，不保证离线可用、远端永久可用或固定哈希。原生导入不会自动选择新主题，界面已说明这一后续操作。第三方大型主题样本和素材的再分发范围仍需逐项确认；核心候选 ZIP 排除了这些素材与本机数据。远端 CI 配置存在，但未推送，不能视为已在远端通过。
